# 그림 2차: 짙은 피부의 밝은 머리 테두리 수정

- 조율자 지시대로 통합 브랜치 `formars0309-cloud/character-game`의 `ca636e47879e997b1ec3f507d5ee55b12bd0b614`를 그림 브랜치에 병합했다. 기존 그림 커밋의 후손이어서 충돌 없이 전진 병합됐다.
- 그림 작업은 직접 수행했다. 그림 담당 파일과 그림 보고서 폴더만 수정했다. 화면·서버 담당 파일에는 추가 변경이 없다.

## 원인과 수정

밝은 기준 피부 위에서 편집한 머리의 가장자리 RGB에 피부색이 섞여 있었다. 차분 추출의 허용 범위를 통과한 혼합색이 짙은 피부 위에서 살구색 선으로 드러났다. 축소한 머리 마스크가 부분 강도인 경계에서는 원래 RGB도 남았다.

`scripts/character-art/edge_cleanup.py`에서 머리 앞·뒤 12개 층의 경계색을 가까운 어두운 머리 선 색으로 정리한다. 원본 1024판과 납품 512판에 모두 적용하며 알파 윤곽은 지우지 않는다. 종족 부속 10개 층은 몸의 피부와 비슷한 접점 경계색만 정리한다. 노란 크림색 뿔은 피부색과 구분하고, 마지막 단계의 비교 기준은 **실제로 WebP에서 디코딩한 종족 몸**이다.

정리한 머리·종족 부속은 무손실 WebP로 저장해 손실 압축의 색 번짐을 막는다. 머리 마스크는 그림이 있는 경계까지 흰색으로 채워 알파와 색 마스크가 중복으로 흐려지지 않게 했다. 금색 머리끈의 수동 제외 영역은 보존했다. 몸·옷·팔레트·manifest 형식은 바뀌지 않았다.

## 회귀 검사와 용량

`test/character-art.test.js`에 **“짙은 피부 합성 시 머리 가장자리에 기준 피부색 화소가 남지 않는다”** 시험을 추가했다. `edge_audit.py`가 실제 납품 WebP를 다시 디코딩해 피부 인접 경계의 밝은 기준 피부 유사색을 검사한다. 보고서 수치나 생성 함수의 성공 여부로 대체하지 않는다. 이 시험에는 Python 3와 Pillow가 필요하며 `CHARACTER_ART_PYTHON`으로 파이썬을 지정할 수 있다.

개발 중 소형 합성 시험의 배율 처리 1건을 수정했고, 부속 경계 검사에서 발견한 여우 귀 잔존색을 정리했다. 중간 전체 시험 두 번은 크림색 뿔의 경계 1화소를 피부색으로 오인해 각각 234/235개가 통과했다. 뿔 색 보존 조건과 실제 WebP 몸 기준 비교를 보완했고, 최종 재생성 뒤에는 235/235개가 통과했다. 공통 필수 검증에서 건너뛴 항목은 없다. 기존 의존성을 그대로 사용했으므로 `npm ci`를 다시 실행할 필요는 없었다.

화면·서버 담당자의 추가 수정은 필요하지 않다. 실제 브라우저 화면의 재검수는 화면 작업자에게 넘길 수 있으며, 이번 작업에서는 납품 파일 합성과 확대 확인판을 직접 검수했다. 배포·main 푸시·운영 API/DB 접근은 수행하지 않았다.
