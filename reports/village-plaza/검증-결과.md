# 그레이스킨 마을 4차 검증 결과

검증일: 2026-11-19. 작업 브랜치: `formars0309-cloud/village-plaza`. 같은 워크트리에서 직접 구현·검증했다. 재위임·하위 워크트리 생성·main 커밋/푸시·배포·공지 게시는 하지 않았다.

## 구현 결과

- 기존 `accountAge`와 보호자 동의만으로 `kids` 어린이 마을 또는 `general` 청소년·성인 마을에 배정한다. 일반 회원에게 마을 선택 기능은 없다.
- 어린이는 유효한 v5 이상 동의가 있어야 입장한다. 어린이 마을은 자유 채팅 입력 요소를 만들지 않고 자유 대화를 서버에서도 거부한다. 둘러보는 운영자에게도 이 규칙이 적용된다. 어린이 수신자 자유 대화 미전달 방어선도 유지했다.
- 각 마을의 채널·위치·입퇴장·대화·감정·신고 버퍼를 분리했다. 채널당 50명이며 서로 다른 마을의 같은 번호 채널도 분리된다. 다른 마을 채널과 일반 회원의 둘러보기 요청은 거부한다.
- 접속 중 가입 연령 구분·동의 상태·운영자 권한이 바뀌면 다음 검사에서 연결을 종료한다. 재접속은 현재 정보로 배정한다. 지도 레지스트리는 id·이름·강조색·지도·입장 조건 함수로 확장할 수 있다.
- 폐기한 추가 회원 설정의 입력·확인·저장·계산·수정·감사 기능을 제거했다. 옛 `/api/village/profile`, `/api/admin/village/profiles`, `/api/admin/village/profiles/:id`는 비회원·회원·운영자 모두 404다. 새 DB에는 `village_profiles`를 생성하지 않는다. 이전 로컬 테이블·추가 열이 남은 DB에서도 이를 읽거나 수정하지 않고 재시작·입장한다. 호환 이관 코드는 만들지 않았다.
- 시행 전 운영자만 입장, 기존 v4 동의 어린이 차단, 1년 자동 정리, 탈퇴 시 아바타·차단 CASCADE 삭제를 유지했다.

```sh

PLAYWRIGHT_EXECUTABLE_PATH='/Applications/Google Chrome.app/Contents/MacOS/Google Chrome' \
```

새 통합 시험은 v5/v4·기존 회원 배정, 위장 입장, 양방향 문맥 격리, 각 마을 51번째 인원, 연령·동의 변경/철회, 운영자 둘러보기·신고/제한 이름, 옛 경로 404와 DB 생성/잔존 테이블 무시를 확인한다. 기존 시험은 비회원·잘못된 Origin, 이동 충돌·과속, 자유 채팅 제한·금칙어·도배, 차단, 신고 스냅숏·운영 권한·제한 만료, 중복 접속, 세션 만료, 종료 안내, revision 409와 보존·탈퇴 정리를 계속 확인한다.

## 결정에서 벗어난 점과 남은 일

확정 결정에서 벗어난 점은 없다. 추가 의존성·빌드 도구·이전 DB 이관 기능을 만들지 않았다. 기존 Dockerfile의 재귀 COPY는 그대로 유효하며 `.dockerignore`에서 새 마을 정의를 허용하고 삭제 모듈은 제외했다.

청소년·성인 마을의 연령은 본인 선택이므로 청소년과 성인이 섞인다. 본인인증을 연동할 때 정의·입장 조건을 더해 분리할 수 있으며 지금 인증 기능은 없다. 보호자 절차도 실제 가족관계·나이를 인증하지 않는다. 기존 v4 어린이의 재동의 접수는 후속 기능이며 실제 동의 확인 전까지 입장을 막는다.

실제 공고·고지 절차와 약관 3절 기준의 적용, v5 문서·서버 동시 배포, 운영 출처·쿠키·WebSocket 프록시·부하·메모리·재접속·다중 인스턴스 및 백업 사본 삭제는 배포 전에 확인해야 한다. 아바타 교체 지점은 `assets/village/avatar.js`의 `drawAvatar(container, avatarData)`다. 건물 모듈 규격과 문 zone은 유지하며 실제 건물 입장·화폐·보상은 후속 범위다.
