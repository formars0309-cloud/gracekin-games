## 자산

`art/slime0.png`부터 `slime9.png`는 Slimeline의 실제 측면 `slime.png`를 기존 `recolorSlime`의 몸 색 판정·색상·밝기·채도 기준으로 변환한 그림이다. 원본 눈·입·광택과 원본 장신구를 보존했다. 장신구 위치는 64×56 논리 좌표에서 실제 몸통 정수리·눈에 맞춘다. 몸통과 장신구는 몸통 하단을 원점으로 같은 눌림·도약 변환을 공유하고 장신구만의 별도 흔들림은 없다. tree/bush 및 효과음 두 개도 같은 프로젝트의 실제 자산이다. 게임 코드와 실제 게임 실행 파일은 불러오지 않는다.

## 서버·계정 경계

- 회차 표시는 서버가 주는 양의 정수 `roundNo`만 사용한다. DB의 첫 회차 `MIN(startsAt)`를 1회로 삼아 10분마다 증가하며 재시작해도 시각 기준으로 이어진다. 정적 화면이 서버보다 먼저 배포되어 `roundNo`가 없거나 유효하지 않으면 공개 상태를 거부하지 않고 상단·구매창은 `이번 경기`, 기록은 경기 날짜·시각으로 표시한다. 내부 `id`·`roundId`는 화면 회차 번호로 노출하지 않는다.
- 그레인은 무료로 지급되는 기존 사이트 공용 게임 화폐다. 현금 구매·충전·환전, 상품·쿠폰·유료 아이템 교환, 회원 간 양도, 유료 재화 전환을 제공하지 않는다. 구매창에는 짧은 무료 안내를, 경기 안내와 계정 가입·잔액 화면에는 상세 범위를 표시한다. 기존 티켓 차감·정산·원장·가입 지급과 성인·로그인 요건은 바꾸지 않는다.
- 공개 상태의 `economy`가 있으면 `mode === 'free-only'` 및 `purchasable`, `cashRedeemable`, `itemExchangeAllowed`, `transferable`, `paidCurrencyConvertible` 다섯 값이 모두 false인지 확인한다. 명시된 정책이 다르거나 불완전하면 구매·금액 변경·취소·모호한 요청 재전송을 차단하며 공개 경기는 계속 표시한다. 이전 서버에서 필드 자체가 없을 때는 무료 기본 안내와 기존 자격 검증을 유지한다.
- 정확한 `https://gracekingames.com`와 `https://www.gracekingames.com`에서만 고정 커뮤니티 API를 사용한다. 그 외에는 현재 출처다. `/api/slime-race/state`, `me`, `tickets`, `history` 네 경로만 허용하고 모든 요청에 credentials/include·no-store를 사용한다.
- 공개 상태의 serverNow와 performance.now 기준점을 동기화한다. 평상시 5초, 출발 카운트·경주 중 1초로 공개 상태를 갱신하며 단계 경계에서는 더 빨리 확인한다. 개인 정보는 창 열기·복귀·구매 결과 및 열린 창의 30초 주기로 갱신한다.
- 현재 서버 좌표 사이만 900ms 보간하며 미래 좌표·우승자를 클라이언트에서 추첨하지 않는다. 서버의 결과 단계·winnerId·finishOrder가 공개된 뒤에만 우승과 순위를 표시한다. 경주는 실제 서버 1분이다.
- 개인 표시를 blur·hidden·pagehide·계정 clear 이벤트에서 지우고 응답 세대도 무효화한다. 비활성 창에서는 개인 데이터를 다시 채우지 않으며 focus/복귀에 재조회한다. 개인 잔액·티켓·계정·기록·요청 식별자는 웹 저장소에 저장하지 않는다.
- POST는 중복 클릭을 잠그고 모호한 응답을 같은 UUID와 같은 본문으로 재확인한다. POST의 과거 멱등 응답으로 잔액을 덮지 않고 항상 GET /me를 재조회한다. 기존 티켓은 총금액 대체, 0은 선택 선수 취소다.
- 성인 자격은 서버 `eligibility.canBet === true`인 경우에만 사용한다. 확인 기능 준비 중·로그인 필요·이메일 확인 필요는 실제 서버 메시지로 안내하며 클라이언트에서 인증 완료로 바꾸지 않는다.
- 2026-10-17 사용자 결정은 본인확인 서비스 연동 전 구매 잠금 유지다. 실제 공급자 연동 전에는 관람·응원만 허용하고 만 19세 자기확인이나 가짜 인증 완료 화면을 추가하지 않는다.
- 배경음은 실제 Slimeline `bgm-spring.mp3`, 효과음은 `sfx-pollen`/`sfx-result`다. 기본 무음이며 소리 버튼을 눌렀을 때만 Audio 객체·음원을 불러온다. 숨김·창 비활성 때 중지한다. 재생 실패는 안내한다.
- 기존 두 게임은 `/games/slimeline/`, `/games/gyeongguk/`의 게임 홈페이지 링크로 이어지고 기존 개인정보처리방침·제보 링크를 보존한다. 게임 실행 코드·게임 엔진·인증 자격증명을 사전 실행/저장하지 않는다.

## 작업자 검수 결과

- `node --check assets/slime-race/race.js`, `git diff --check` 통과.
- 원본 그림에서 내장한 슬라임·장신구·나무·관목 22개를 Pillow로 실제 디코딩해 확인했다.
- HTTP 계약 fixture를 사용한 Chromium 브라우저에서 1024/390/320px 화면, 5명 스크롤 선택, 구매·취소, 중복 클릭 잠금 및 동일 requestId 재확인, blur clear/복귀, Tab 초점 순환, Escape, 접속 오류·구매 차단을 확인했다. 재검수에서 이미지 요청 실패와 콘솔 오류는 없었다.
- 초기 `npm test`는 새 워크트리에 better-auth 의존성이 없어 실패했다. `npm ci --ignore-scripts --no-audit --no-fund` 후 다시 실행하여 103개 모두 통과했다.
- 실제 서버·시험 성인 확인 어댑터·DB를 통한 구매/변경/취소/정산 통합 검수는 조율자와 독립 QA 작업자가 담당한다. 작업자 fixture 검증은 실제 운영 서버 검증을 대신하지 않는다.
- 실물 휴대전화의 프레임률과 보조기기 전수 검수는 하지 않았다. 실제 음원은 원본 파일 존재·브라우저 재생 경로를 확인했으며 청취 취향 검수는 별도다.
- 변경은 index.html, assets/slime-race/** 및 이 문서에 한정했다. 운영 계정·서버·다른 게임 코드는 수정하지 않았으며 공개 배포·푸시는 하지 않았다.

## 무료 정책 화면 후속 검수

- 구매창의 기존 회차·잔액 안내 줄을 무료 안내로 재사용하고, 잔액은 선택 선수 요약의 중복 성향 자리에 옮겼다. 성향은 선수 목록에 계속 표시한다. 새 모션이나 결제·교환 기능은 추가하지 않았다. 계정 페이지의 준비 중 설명은 현재 공용 무료 화폐 정책으로 갱신했다.
- 임시 DB의 실제 로컬 서버에서 게스트의 로그인·성인 확인 잠금, 가입 화면 안내, 이미지 정상 로드·콘솔 오류 없음과 320/390/1024px 가로 넘침 없음을 확인했다. 무료 안내 높이는 세 폭 모두 18.59px 한 줄이며, 320×800px에서 첫 선수 메타 전체와 두 번째 선수가 보인다. 팝업 높이는 784px, 목록 스크롤 영역은 게스트 기준 358px다.
- 실제 서버가 아직 economy 없는 기존 응답을 반환하는 조건을 확인했고, 별도 HTTP 시험 응답으로 정확한 무료 계약·필드 누락·명시 정책 충돌을 검증했다. 무료/누락은 시험 성인 자격 아래 1,000 그레인 티켓 구매 후 29,000 잔액, 취소 후 30,000을 확인했다. 정책 충돌은 구매·취소 차단과 선수 5명 관람 유지가 통과했다. 시험 응답은 운영 계정·실제 잔액 검증을 대신하지 않는다.
- `node --check assets/slime-race/race.js`, `git diff --check`, `npm test` 118개 통과. 무료 정책 서버와의 통합 후 최종 회귀는 조율자·QA가 담당한다. 변경 범위는 index.html, account/index.html, assets/slime-race/race.js·race.css 및 이 문서다. 운영 DB·main·이전 워크트리는 수정하지 않았고 푸시·배포하지 않았다.
