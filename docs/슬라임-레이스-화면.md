## 자산

`art/slime0.png`부터 `slime9.png`는 Slimeline의 실제 측면 `slime.png`를 기존 `recolorSlime`의 몸 색 판정·색상·밝기·채도 기준으로 변환한 그림이다. 원본 눈·입·광택과 원본 장신구를 보존했다. 장신구 위치는 `cosmeticsCatalog.ts`의 64×56 논리 좌표를 따른다. tree/bush 및 효과음 두 개도 같은 프로젝트의 실제 자산이다. 게임 코드와 실제 게임 실행 파일은 불러오지 않는다.

## 서버·계정 경계

- 정확한 `https://gracekingames.com`와 `https://www.gracekingames.com`에서만 고정 커뮤니티 API를 사용한다. 그 외에는 현재 출처다. `/api/slime-race/state`, `me`, `tickets`, `history` 네 경로만 허용하고 모든 요청에 credentials/include·no-store를 사용한다.
- 공개 상태의 serverNow와 performance.now 기준점을 동기화한다. 평상시 5초, 출발 카운트·경주 중 1초로 공개 상태를 갱신하며 단계 경계에서는 더 빨리 확인한다. 개인 정보는 창 열기·복귀·구매 결과 및 열린 창의 30초 주기로 갱신한다.
- 현재 서버 좌표 사이만 900ms 보간하며 미래 좌표·우승자를 클라이언트에서 추첨하지 않는다. 서버의 결과 단계·winnerId·finishOrder가 공개된 뒤에만 우승과 순위를 표시한다. 경주는 실제 서버 1분이다.
- 개인 표시를 blur·hidden·pagehide·계정 clear 이벤트에서 지우고 응답 세대도 무효화한다. 비활성 창에서는 개인 데이터를 다시 채우지 않으며 focus/복귀에 재조회한다. 개인 잔액·티켓·계정·기록·요청 식별자는 웹 저장소에 저장하지 않는다.
- POST는 중복 클릭을 잠그고 모호한 응답을 같은 UUID와 같은 본문으로 재확인한다. POST의 과거 멱등 응답으로 잔액을 덮지 않고 항상 GET /me를 재조회한다. 기존 티켓은 총금액 대체, 0은 선택 선수 취소다.
- 성인 자격은 서버 `eligibility.canBet === true`인 경우에만 사용한다. 확인 기능 준비 중·로그인 필요·이메일 확인 필요는 실제 서버 메시지로 안내하며 클라이언트에서 인증 완료로 바꾸지 않는다.
- 배경음은 실제 Slimeline `bgm-spring.mp3`, 효과음은 `sfx-pollen`/`sfx-result`다. 기본 무음이며 소리 버튼을 눌렀을 때만 Audio 객체·음원을 불러온다. 숨김·창 비활성 때 중지한다. 재생 실패는 안내한다.
- 기존 두 게임은 `/games/slimeline/`, `/games/gyeongguk/`의 게임 홈페이지 링크로 이어지고 기존 개인정보처리방침·제보 링크를 보존한다. 게임 실행 코드·게임 엔진·인증 자격증명을 사전 실행/저장하지 않는다.

## 작업자 검수 결과

- `node --check assets/slime-race/race.js`, `git diff --check` 통과.
- 원본 그림에서 내장한 슬라임·장신구·나무·관목 22개를 Pillow로 실제 디코딩해 확인했다.
- HTTP 계약 fixture를 사용한 Chromium 브라우저에서 1024/390/320px 화면, 5명 스크롤 선택, 구매·취소, 중복 클릭 잠금 및 동일 requestId 재확인, blur clear/복귀, Tab 초점 순환, Escape, 접속 오류·구매 차단을 확인했다. 재검수에서 이미지 요청 실패와 콘솔 오류는 없었다.
- 초기 `npm test`는 새 워크트리에 better-auth 의존성이 없어 실패했다. `npm ci --ignore-scripts --no-audit --no-fund` 후 다시 실행하여 103개 모두 통과했다.
- 실제 서버·시험 성인 확인 어댑터·DB를 통한 구매/변경/취소/정산 통합 검수는 조율자와 독립 QA 작업자가 담당한다. 작업자 fixture 검증은 실제 운영 서버 검증을 대신하지 않는다.
- 실물 휴대전화의 프레임률과 보조기기 전수 검수는 하지 않았다. 실제 음원은 원본 파일 존재·브라우저 재생 경로를 확인했으며 청취 취향 검수는 별도다.
- 변경은 index.html, assets/slime-race/** 및 이 문서에 한정했다. 운영 계정·서버·다른 게임 코드는 수정하지 않았으며 공개 배포·푸시는 하지 않았다.
