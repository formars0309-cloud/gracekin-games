# 슬라임 레이스 검증 기록

2026-10-17 작업 기록이다. 현재 문서는 시험 계획과 확인된 사전 조건을 구분한다. 구현 완료나 공개 배포 완료를 뜻하지 않는다. 확정 요구사항은 [기획 정본](기획/슬라임-레이스.md)을 따른다.

## 확인한 사전 조건

- 기준 커밋: `fdfb347`.
- QA 작업 브랜치: `formars0309-cloud/slime-race-qa`. `main`을 직접 수정하지 않는다.
- 로컬 Node.js는 `v24.20.0`으로 저장소 요구 범위 `>=24.15.0 <25`에 들어간다.
- `Dockerfile`은 `server/`, `assets/`를 복사하지만 `.dockerignore`는 파일별 명시 허용 목록이다. 새 레이스 파일과 상위 폴더의 허용 여부를 별도로 검사해야 한다.
- `_config.yml`은 서버·문서·시험·운영 설정·의존성 폴더를 Pages 공개 출력에서 제외한다.
- `fly.toml`은 유휴 정지 및 최소 실행 머신 0대다. 상시 실행을 보장하는 운영 구성은 아직 아니다. 이번 작업에서 설정 변경·비용 발생 조치·배포는 하지 않는다.
- 성인 확인 방식은 아직 미확정이다. 기존 `14plus` 계정을 성인으로 간주하지 않는다.

## 실행 결과

레이스 구현 통합 전 기준 회귀는 다음과 같이 확인했다.

| 명령 | 결과 |
| --- | --- |
| `npm ci --ignore-scripts --no-audit --no-fund` | 의존성 설치 성공 |
| `npm test` | 기존 103개 시험 통과, 실패·생략 0개 |
| `python3 scripts/verify_site.py` | 2,040개 확인·6개 페이지 통과 |
| `python3 -m unittest discover -s tests/security-review -p 'test_*.py'` | 정적 검사기 회귀 11개 통과 |

아직 레이스 구현을 통합한 시험은 수행하지 않았다. 운영 데이터베이스·운영 메일·운영 시험 계정은 사용하지 않는다. 서버 시험은 자동 생성한 임시 디렉터리의 별도 SQLite DB와 메모리 메일함에서 진행하고 시험 종료 후 해당 자료만 정리한다.

## 공개 전 남은 조건

- 사용자의 성인 확인 방식 결정과 그 결정에 따른 구매 자격 검증.
- 통합 구현의 자동·독립 API·브라우저 검수 완료.
- 운영 DB 백업과 복구 검증을 포함한 배포 절차 준비.
- 상시 실행·비용에 대한 운영 결정. 현재 유휴 정지 설정만으로 24시간 실제 경주 실행을 보장하지 않는다.
- 공개 배포에 대한 사용자의 명시적 요청. 현재 승인은 구현까지다.
