## 2026-10-17 무료 공용 그레인 정책 반영

사용자의 ‘그레인을 무료 화폐로만 사용’하는 사이트 구현 요청에 따라 정책을 갱신했다. 앞선 구현·검수 이력은 위에 보존한다. 이번 기준은 기존 경주 구현과 운영 닉네임 전달 변경 `06c3d3d`를 통합한 `e4e43ed`이며 QA 작업 브랜치는 `formars0309-cloud/slime-race-free-review`다. 운영 배포·DB 변경·main 푸시는 수행하지 않는다. 사용자가 본인확인 서비스 연동 전 구매 잠금 유지를 확정했다. 관람·응원은 허용하며 만 19세 자기확인이나 가짜 인증 완료는 도입하지 않는다.

### 정책과 실제 코드 범위

- 기존 사이트 공용 그레인 지갑·원장, 신규 가입 30,000 지급 자격·횟수, 레이스 티켓·취소·정산은 유지한다. 경주 전용 포인트를 만들지 않는다.
