## 검사 규칙

1. 대상 HTML은 `/assets/shared/fonts.css`를 첫 스타일시트로 불러온다.
2. 공개 CSS, HTML의 `<style>`·`style=`에서 글꼴 값은 역할 변수·`inherit`·`initial`만 허용한다. 단축 속성의 크기·행간은 구별하고 변수 뒤의 직접 대체 글꼴도 거부한다. 주석·문자열의 예시는 선언으로 오인하지 않는다.
3. 구글 폰트 요청은 공용 파일에만 둔다. 두 폰트 출처의 HTML `preconnect`는 허용한다.
4. 손글씨 변수는 공용 정의를 제외하면 `games/slimeline/`와 `assets/community/community.css`에서만 허용한다.
5. `PENDING_FONT_MIGRATION`에는 `community/index.html`·`assets/community/community.css`만 넣고 1·2·3번만 임시 제외한다. 커뮤니티 통합 때 조율자가 비워야 한다.

루트·`assets/`·`games/`·`community/`·`account/`의 공개 CSS를 검사하며 서버·설치 모듈·시험 자료는 제외한다. 회귀 시험에는 각 규칙의 통과·실패, 임시 제외의 범위와 제거 후 동작을 포함했다.
