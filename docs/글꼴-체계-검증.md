## 검사 규칙

1. 대상 HTML은 `/assets/shared/fonts.css`를 첫 스타일시트로 불러온다.
2. 공개 CSS, HTML의 `<style>`·`style=`에서 글꼴 값은 역할 변수·`inherit`·`initial`만 허용한다. 단축 속성의 크기·행간은 구별하고 변수 뒤의 직접 대체 글꼴도 거부한다. 주석·문자열의 예시는 선언으로 오인하지 않는다.
3. 구글 폰트 요청은 공용 파일에만 둔다. 두 폰트 출처의 HTML `preconnect`는 허용한다.
4. 손글씨 변수는 공용 정의를 제외하면 `games/slimeline/`와 `assets/community/community.css`에서만 허용한다.
5. `PENDING_FONT_MIGRATION`에는 `community/index.html`·`assets/community/community.css`만 넣고 1·2·3번만 임시 제외한다. 커뮤니티 통합 때 조율자가 비워야 한다.

루트·`assets/`·`games/`·`community/`·`account/`의 공개 CSS를 검사하며 서버·설치 모듈·시험 자료는 제외한다. 회귀 시험에는 각 규칙의 통과·실패, 임시 제외의 범위와 제거 후 동작을 포함했다.

## 화면 비교

macOS Chrome에서 실제 로컬 애플리케이션 서버를 열고, 대표 홈·계정·운영 화면·비공개 버그 제보·개인정보처리방침·이용약관·슬라임 라인 소개·경국지계 소개를 각각 1,440·390·320px 너비와 1,000px 화면 높이에서 비교했다. 운영 화면과 버그 제보는 임시 로컬 계정으로 로그인해 내부 양식까지 열었다. 페이지 끝까지 스크롤한 후 전체 화면을 저장했다.

- 원본·수정본 각 24장, 총 48장의 전체 스크린샷과 24개의 상단 전후 비교 이미지를 보존했다.
- 24개 조건 모두 문서 너비와 화면 너비가 같았다. 화면 밖 본문·제목·기능 글자, 새 겹침 후보, 콘솔 오류, 미처리 자바스크립트 오류, HTTP 오류는 없었다.
- `document.fonts.ready`·로드된 `FontFace`와 브라우저의 실제 글리프 렌더링 정보를 함께 확인했다. 로고는 Cinzel, 제목은 Noto Serif KR, 본문·기능 글자는 Noto Sans KR 웹폰트로 그려졌다. 이미지로 된 게임 제목은 섹션 제목에서 글꼴을 확인했다.
- 슬라임 라인 손글씨는 Nanum Pen Script 웹폰트, 소개 본문·버튼은 Noto Sans KR로 확인했다. 경국지계 소개 본문은 Noto Serif KR를 유지하고 메뉴·시작 버튼은 Noto Sans KR로 확인했다.
- 브라우저의 내부 글꼴명은 `Noto Serif KR ExtraLight`·`Noto Sans KR Thin`·`Nanum Pen`으로 보고되기도 한다. 실제 CSS의 요청 굵기와 가족명, 웹폰트 사용 여부를 함께 확인했다.
- 계정·운영·버그 제보·방침·약관 제목이 고딕에서 명조로 바뀐 점이 가장 눈에 띈다. 로고도 Georgia에서 Cinzel로 통일됐다. 슬라임 라인은 명조 제목과 손글씨를 실제 웹폰트로 제공한다. 경국지계의 역사 분위기 본문은 유지됐다.
- 계정 390px에서 소개 제목이 한 줄 더 감기는 등 일부 줄바꿈이 달라졌다. 개인정보처리방침·약관은 새 본문 글꼴의 폭 때문에 문서가 길어졌지만 잘림·겹침은 없었다. 기존 표의 내부 가로 스크롤도 유지됐다.
- 장식 밑줄·SVG·로고 이미지 때문에 일부 요소의 `scrollWidth`가 자체 상자보다 큰 기존 사례는 전후 모두 존재했다. 새 초과 사례는 없었고 실제 글자 잘림으로 이어지지 않았다.
- 홈의 경주 시계·출전 순서·경주 상태는 시간에 따라 달라지므로 전후 이미지의 해당 차이를 글꼴 변경으로 판단하지 않았다.
- 상단 계정 요약 요청의 `net::ERR_ABORTED`는 원본 7건·수정본 6건이었다. 화면 전환·포커스 해제 때 취소되는 요청이며 콘솔 오류나 HTTP 오류는 없었다.
