# 경국지계 커뮤니티 개편 기획

2026-10-18 사용자 요청으로 시작했다. 같은 날 [슬라임 라인 커뮤니티 개편](슬라임라인-커뮤니티-개편.md)을 공개 배포한 뒤, 경국지계 커뮤니티도 같은 방식으로 게임 세계와 이어 붙이기로 했다. 첫 화면·게시판 이름·빈 상태 그림 세 가지는 사용자가 조율자 추천안으로 확정했다. 2026-10-19 사용자 요청으로 구현했다(작업 브랜치 `formars0309-cloud/gyeongguk-community-redesign`, 커밋 `7941250`·`2429bfe`·`ce8ffa2`, main에 로컬 통합). 조율자 검수에서 데스크톱 첫 화면 그림 왼쪽 경계가 보여 `mask-image`로 녹이도록 고쳤다. 검증: `npm test` 179개, `scripts/verify_site.py` 2,910개, `git diff --check` 통과. 경국지계·슬라임 라인을 1,440·390·320px에서 확인했고 반대 게임 그림 요청은 없었다. 로그인·보상 상태는 모의 응답으로 확인했다. **공개 배포 전**이다.

구현에서 정한 세부: 첫 화면 최소 높이 420px, 로고 280px(모바일 220px), 탭 그림 28px, 빈 상태 그림 132px, 모서리 2px, 주 버튼 모서리 9px 깎기. 게임 고르기 화면(`game` 값 없음)은 기본 보라 테마(`#17131f`)다.

## 1. 현재 문제

2026-10-18 운영 화면(`/community/?game=gyeongguk&board=free`)을 경국지계 소개 페이지(`/games/gyeongguk/`)·개편된 슬라임 라인 커뮤니티와 1,440px로 비교했다.

1. **소개 페이지와 단절.** 소개 페이지는 수묵 산수·매화·보름달 위에 여포·초선 그림(`assets/gyeongguk/hero.webp`), 붓글씨 로고(`title.png`), 붉은 낙관색(`#a42c25`), 각진 START 버튼으로 개성이 뚜렷하다. “커뮤니티”를 누르면 그림 없는 한지색 틀과 갈색(`#875331`) 버튼으로 넘어가 다른 사이트처럼 느껴진다.
2. **빈 장식.** 큰 제목 오른쪽의 희미한 원과 막대 두 개(`.hero-ornament`)는 무엇인지 알아보기 어렵다.
3. **이름 불일치.** 소개 페이지는 ‘새 소식’, ‘천하의 이야기 — 자유 게시판 · 덱 연구 · 전략 이야기’인데 커뮤니티는 ‘자유게시판 · 덱 연구 · 전략·공략 · 공지사항’이고 묶음 제목은 슬라임 라인과 같은 ‘우리들의 이야기’다.
4. **빈 게시판.** 슬라임 라인은 빈 게시판에 슬라임 그림이 나오지만 경국지계는 글자만 있다.
5. **슬라임 자원 낭비.** `community/index.html`이 `data-game="slimeline"`과 슬라임 밤 숲 그림(`fetchpriority="high"`)으로 시작해, 경국지계 화면에서도 슬라임 그림을 내려받는다. 테마가 스크립트 실행 뒤에 바뀌어 첫 순간 남색 화면이 비칠 수 있다(구현 때 실측).

쓸 그림은 저장소에 이미 있고 커뮤니티 서버 허용 목록(`.dockerignore`)에도 들어 있다: `hero.webp`(1756×896), `title.png`(2048×768), `tiles.webp`(1536×1024, 3×2 타일), 카드 그림 3장.

## 2. 방향: 소개 페이지의 한지·먹·낙관을 이어 쓴다

슬라임 라인 개편과 같은 틀(그림 띠 첫 화면 → 게시판 탭 → 목록과 안내 칸)을 쓰되, 모양과 색은 경국지계 소개 페이지에서 가져온다. 슬라임 라인이 둥글고 밤하늘이라면 경국지계는 각지고 한지·먹·붉은 낙관이다.

### 2-1. 경국지계 전용 테마

- 기존 `body[data-game=gyeongguk]` 블록을 소개 페이지 값 기준으로 다시 정한다: 바탕 한지(`--paper:#f8f6f1`), 글자 먹색(`--ink:#242321`), 강조 낙관색(`--red:#a42c25`), 선(`--line:#c6bcb0`).
- 기본 버튼·활성 탭·링크 강조를 갈색에서 낙관색으로 바꾼다. 보조 글자색은 소개 페이지의 `#85807b`가 한지 위에서 4.5:1에 못 미치므로 현재 `#62635a` 수준을 유지한다.
- 모서리는 각지게(반경 0~3px), 주 버튼은 소개 페이지 START처럼 한쪽 모서리를 깎은 모양(`clip-path`)과 안쪽 테두리를 쓴다.
- 본문 대비는 WCAG AA(본문 4.5:1, 큰 글씨 3:1) 이상.

### 2-2. 첫 화면

- `hero.webp`를 넓은 띠로 쓴다. 왼쪽 매화·마을 쪽에 글을 놓고 오른쪽에 두 인물이 보이게 한다. 바탕이 밝으므로 슬라임 라인처럼 어두운 그라데이션이 아니라 **왼쪽에서 한지색으로 옅어지는 그라데이션**으로 먹색 글자 대비를 확보한다.
- 글 순서: 붓글씨 로고 `title.png` → 제목 “커뮤니티” → 한 줄 소개 “한 장의 계략, 한 판의 이야기가 모이는 곳.”(현재 문장 유지) → “게임 START”(낙관색 각진 버튼)와 “게임 소개로 돌아가기”.
- 영문·장식 요소(`.hero-ornament`)와 작은 제목 ‘경국지계’ 글자는 로고 그림이 대신하므로 없앤다(로고 `alt="경국지계"`).
- 띠 테두리는 소개 페이지 카드처럼 얇은 먹선(`#bbb0a2`)과 각진 모서리.
- 650px 이하: 소개 페이지 모바일처럼 글을 위(한지 바탕)에, 그림을 아래 띠로 나눈다. 그림 위치는 인물이 잘리지 않게 오른쪽(소개 페이지 `82%`) 기준. 390·320px에서 버튼 두 개가 한 줄에 들어가지 않으면 START를 위로 쌓는다.

### 2-3. 게시판 이름과 탭

화면에 보이는 이름만 소개 페이지와 맞춘다. 서버의 게시판 값과 주소는 바꾸지 않는다.

| 서버 값 | 현재 | 변경 | 탭 그림(`tiles.webp`) |
| --- | --- | --- | --- |
| `free` | 자유게시판 | 자유 게시판 | 달밤의 궁궐 누각(왼쪽 위) |
| `deck` | 덱 연구 | 덱 연구 | 책과 붓이 놓인 책상(가운데 위) |
| `strategy` | 전략·공략 | 전략 이야기 | 나부끼는 깃발(오른쪽 위) |
| `notice` | 공지사항 | 새 소식 | 매화와 보름달 아래 궁궐(왼쪽 아래) |

- 묶음 제목 ‘우리들의 이야기’는 경국지계에서 ‘천하의 이야기’로 바꾼다(슬라임 라인은 그대로).
- 탭은 각진 사각형. 왼쪽에 해당 타일 그림을 작은 정사각 썸네일(24~28px)로 넣는다. 활성 탭은 먹색 바탕·한지색 글자·아래 낙관색 선. 모바일에서는 가로로 넘긴다.
- 게시판 소개 문장은 소개 페이지 카드 문구를 살려 다시 쓴다(합니다체 유지).

| 게시판 | 소개 문장 |
| --- | --- |
| 자유 게시판 | 한 판을 마친 소감과 다양한 이야기를 나누는 곳입니다. |
| 덱 연구 | 더 강한 한 수를 위해 카드 조합과 덱을 연구합니다. |
| 전략 이야기 | 대전에서 찾은 수와 계략, 천하를 보는 또 다른 시선을 나눕니다. |
| 새 소식 | 경국지계의 공식 소식과 게임 이용 안내를 확인하세요. |

### 2-4. 빈 게시판과 첫 글 유도

- 글이 없을 때 해당 게시판의 타일 그림을 액자처럼(정사각 120~140px, 얇은 먹선 테두리) 보여 준다. 슬라임 라인의 슬라임 그림 자리와 같은 구조를 게임별 그림으로 일반화한다.
- 게시판별 문장(첫 줄 제목, 둘째 줄 설명):

| 게시판 | 제목 | 설명 |
| --- | --- | --- |
| 자유 게시판 | 아직 고요합니다 | 첫 이야기를 남겨 주세요. |
| 덱 연구 | 아직 펼쳐진 덱이 없습니다 | 당신의 첫 조합을 보여 주세요. |
| 전략 이야기 | 아직 드러난 계략이 없습니다 | 대전에서 찾은 한 수를 들려주세요. |
| 새 소식 | 새 소식을 준비하고 있습니다 | 곧 천하의 소식을 전하겠습니다. |

- 글쓰기 버튼·보상 문장(`grainRewardPolicy`)·비로그인 로그인/회원가입 버튼·검색 결과 없음 구분은 슬라임 라인 개편에서 만든 공용 동작을 그대로 쓴다.

### 2-5. 안내 칸·계정 줄

- 구조(그레인 받는 방법, 커뮤니티 안내, 계정 안내)는 슬라임 라인 개편 그대로 둔다.
- 카드 제목 앞에 작은 낙관색 사각 표식을 두고, 카드 모서리는 각지게 유지한다.

### 2-6. 슬라임 자원 분리와 첫 화면 깜빡임

- `community/index.html`의 게임별 그림은 `src` 없이 두고, 게임이 정해진 뒤 스크립트가 해당 게임 그림만 넣는다. 경국지계에서 슬라임 그림을, 슬라임 라인에서 경국지계 그림을 내려받지 않는다.
- 게임 판별(주소의 `game` 값)은 `<head>`의 기존 `host.js` 또는 작은 인라인 처리에서 먼저 해 `data-game`과 `theme-color`를 첫 그림 전에 정한다. `game` 값이 없을 때(게임 고르기 화면)의 기본 테마도 함께 정한다.
- 첫 화면 그림은 `fetchpriority="high"`를 해당 게임 그림에만 준다.

### 2-7. 글꼴

[글꼴 체계](글꼴-체계.md)를 그대로 따른다. 제목 Noto Serif KR(`--font-display`), 본문 Noto Sans KR(`--font-body`). 붓글씨는 로고 그림으로만 쓰므로 새 글꼴 예외는 없다.

## 3. 범위와 영향

- 수정 파일: `community/index.html`, `assets/community/community.css`, `assets/community/community.js`, 필요하면 `assets/community/host.js`, 회귀 시험(`test/`)과 `scripts/verify_site.py`의 관련 검사.
- 서버 API·DB 변경 없음. 게시판 값·주소·게시글·보상·신고 기능은 그대로다.
- 경국지계 소개 페이지는 고치지 않는다(이름이 이미 맞다).
- 슬라임 라인 커뮤니티는 2-6(그림 지연 로드·테마 선결정)만 영향을 받는다. 화면이 어제 배포본과 같은지 회귀 확인한다.
- 새 그림을 만들지 않는다. 쓰는 그림은 모두 `.dockerignore` 허용 목록에 이미 있다.

## 4. 완료 기준

1. 경국지계 소개 페이지 → 커뮤니티 이동 시 같은 그림·로고·한지·낙관색이 이어진다.
2. 1,440·390·320px에서 첫 화면 인물이 잘리지 않고 가로 넘침·콘솔 오류가 없다.
3. 게시판 이름 4개와 묶음 제목이 소개 페이지와 같고, 기존 주소(`?board=free`·`deck`·`strategy`·`notice`)가 그대로 동작한다.
4. 빈 게시판 4종이 각자 타일 그림과 문장을 보여 주고, 검색 결과 없음·비로그인·로그인·보상 미자격 상태별 문장이 맞다.
5. 경국지계 화면 네트워크 기록에 슬라임 그림(`assets/slimeline/hero.webp`·`title.png`)이 없고, 반대도 같다. 첫 화면에 다른 게임 테마가 비치지 않는다.
6. 슬라임 라인 커뮤니티가 어제 배포본과 같게 동작한다(같은 세 폭 비교).
7. 본문 대비 4.5:1 이상, 키보드로 탭·버튼 이동 가능, `prefers-reduced-motion`에서 장식 움직임 없음.
8. `npm test`, `python3 scripts/verify_site.py`, `git diff --check`가 통과한다.

## 5. 구현 순서 제안 (사용자가 명시한 뒤)

1. 게임 판별 선처리와 게임별 그림 지연 로드(2-6) — 두 게임 공통 기반
2. 경국지계 테마 변수·버튼·탭 모양
3. 첫 화면 그림 띠와 모바일 배치
4. 게시판 이름·묶음 제목·소개 문장·빈 상태 그림과 문장
5. 세 폭 화면 비교 검수(경국지계·슬라임 라인 각각, 로그인·비로그인)
6. 공개 배포는 사용자 요청 시 Pages와 커뮤니티 서버에 함께 반영

## 6. 배포 후 수정 요청 (2026-10-19, 구현 대기)

공개 배포 뒤 사용자가 화면을 보고 세 가지를 요청했다. 세부는 조율자 추천대로 정했고, 공개 화면에 CSS·DOM을 덧씌운 시안으로 확인했다(코드 변경 없음).

1. **경국지계 버튼을 연한 푸른색 계통으로.** 붉은 낙관색 버튼이 눈이 아프다는 의견이다.
   - 주 버튼(START·글쓰기·회원가입·등록): 바탕 `#dce8f1`, 글자 `#1d3a52`, 안쪽 테두리 `#9db7cb`, 마우스를 올리면 `#cddff0`. 깎은 모서리 모양은 유지한다.
   - 링크·강조 글자(`--accent`): 쪽빛 `#2f5d7c`(한지 바탕 대비 약 6:1), 진한 강조 `#1f4560`.
   - 활성 탭 밑줄·안내 칸 제목 표식: `#7fa8c6`.
   - 붉은 낙관은 로고 그림 속 도장에만 남는다. 오류 문구 색(`#a03f32`)은 경고 의미라 유지한다.
2. **장식 화살표 없애기(두 게임 공통).** `게임 START ↗`, `게임 홈페이지 ↗`, `게임 소개로 돌아가기 ↗`, `검색 ↗`, `글쓰기 ＋`, 글 목록 줄 끝 `↗`, `… 보기 →`, `의견 보내기 ↗`, 빈 상태·검색 결과 링크의 `→`를 모두 뺀다. 방향 자체가 뜻인 페이지 넘김(`← 이전`·`다음 →`)과 `← 목록으로`만 남긴다.
3. **새 소식(공지) 탭을 맨 왼쪽으로(두 게임 공통).** 탭 순서는 새 소식 → 자유 → 덱 연구/공략 나누기 → 전략 이야기/작품 자랑이다. 주소에 게시판이 없을 때 열리는 기본 게시판이 이미 `notice`라서 처음 열린 탭과 맨 왼쪽 탭이 같아진다.

검증: 경국지계 버튼 글자 대비 4.5:1 이상, 두 게임 1,440·390·320px, 화살표가 빠진 링크도 밑줄·색으로 링크임을 알아볼 수 있는지, 기존 시험의 화살표 문구 기대값 갱신.
