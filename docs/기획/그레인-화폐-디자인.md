## 기본 운영 방향

2026-10-16 사용자가 다음 기본 운영 방향을 정했다.

- 획득 방법: 이벤트로 그레인을 획득할 수 있다.
- 사용처: Gracekin Games 사이트에 있는 게임들에서 그레인을 사용한다.

### 신규 가입 이벤트

사이트 신규 가입 이벤트로 **30,000 그레인**을 지급한다.

지급 시점(이메일 확인 전·후), 기존 회원 소급 지급 여부, 이벤트 기간은 미확정이다. 다른 이벤트의 획득 조건과 지급량, 게임별 구체적인 사용 방식도 미확정이다.

현재 확정 범위는 이름·이미지와 위 기본 운영 방향이다. 화폐 UI·잔액·결제·경제 시스템의 기능 구현은 현재 범위가 아니며, 나머지 미확정 경제 정책은 그대로 둔다.
