## 기본 운영 방향

2026-10-16 사용자가 다음 기본 운영 방향을 정했다.

- 획득 방법: 이벤트로 그레인을 획득할 수 있다.
- 사용처: Gracekin Games 사이트에 있는 게임들에서 그레인을 사용한다.

### 신규 가입 이벤트

사이트 신규 가입 이벤트로 **30,000 그레인**을 지급한다.

2026-10-16 사용자의 요청으로 가입 보상과 지갑을 공개 배포했다. 현재 지급 기준은 다음과 같다.

- 새 계정이 이메일 확인을 완료할 때 계정당 한 번 지급한다. 확인 전에는 지급하지 않는다.
- 기능 적용 전에 존재한 회원은 이메일 미확인 상태를 포함해 소급 지급하지 않는다.
- 보호자 동의 승인을 거쳐 가입한 어린이도 같은 기준을 적용한다. 동의가 철회된 계정에는 지급·지갑 조회를 허용하지 않는다.
- 인증 메일 재발송·재인증·중복 또는 동시 확인·로그인·서버 재시작으로 추가 지급하지 않는다.
- 서버 DB에 계정별 잔액과 지급 내역을 저장하고, 로그인한 본인의 계정 화면에 정본 아이콘과 함께 표시한다.
- 이메일 확인과 지급은 함께 성공하거나 함께 취소된다. 지급 저장에 실패하면 같은 확인 링크로 재시도할 수 있다.

이벤트 종료일은 아직 정하지 않았다. 이번 구현은 별도 종료일 없이 적용 이후 신규 가입 계정의 자격을 기록한다. 종료할 때에는 새 자격 부여를 중단할 시점과 이미 가입했으나 이메일을 확인하지 않은 계정의 처리를 먼저 정한다.

게임별 구체적인 사용 방식과 가격, 다른 이벤트의 획득 조건·지급량, 유효기간·회수 정책은 미확정이다. 실제 게임 사용·일반 운영자 지급·충전·결제·회원 간 송금은 구현하지 않았다.

공개 화면·API·운영 데이터 보존과 모바일 화면을 확인했다. 실제 가입 → 이메일 확인 → 30,000 그레인 지급은 앞선 격리 DB의 자동·브라우저 시험으로 검증했으며 운영 시험 회원은 만들지 않았다. 배포 식별자와 검증 범위는 [배포 기록](../커뮤니티-배포.md)에 남겼다.
