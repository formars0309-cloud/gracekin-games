# gracekingames 공통 계정과 게임 연결 기획

- 기록일: 2026-10-16, 한국시간.
- 상태: 사용자 구현 요청에 따라 사이트 공통 계정과 보호자 동의 가입을 1차 구현한다. 두 게임의 실제 로그인 연결·기록 저장은 후속 범위이며 공개 배포는 별도 요청 때 진행한다.
- 대상: gracekingames 사이트·커뮤니티, 슬라임 라인, 경국지계.
- 요청: 공통 계정 구상에 사용자가 확정한 게스트 체험 방식, 법정대리인 동의를 거친 어린이 가입, 두 게임의 실제 이용자 0명이라는 현황을 반영한다.

## 1. 목표와 반영 범위

슬라임 라인과 경국지계는 게스트로 먼저 체험하고, 기록을 계정에 연결하거나 회원 기능을 이용할 때 gracekingames 공통 계정에 가입·로그인하는 방향으로 정한다. 회원은 같은 계정으로 두 게임을 이용하되 게임별 데이터는 각각 유지한다. 회원가입·로그인·계정 복구는 공통 계정 체계에서 관리하고, 게임별로 독립적인 가입·비밀번호 관리 체계를 추가하지 않는다.

사이트를 먼저 방문하도록 강제하지 않는다. 사이트에서 게임을 선택하거나 게임 주소·앱으로 직접 들어온 경우 모두 공통 가입·로그인을 시작할 수 있게 한다. 인증 후에는 시작했던 게임으로 돌아온다.

2026-10-16 사용자 구현 요청으로 사이트와 커뮤니티의 공통 이메일 계정, 이메일 확인·비밀번호 복구, 보호자 동의 가입을 1차 범위로 구현한다. 대문과 게임 소개에 계정 진입 링크를 추가하되 실제 게임 저장소의 코드·실사용 에셋, DNS·소셜 로그인 등록 설정은 변경하지 않는다. 대회와 경품은 공통 계정의 후속 활용으로 기록하며 운영 규칙을 확정하지 않는다.

만 14세 미만 어린이도 법정대리인(보호자)의 동의 절차를 거쳐 공통 계정에 가입할 수 있게 한다. 1차 구현은 보호자 성명·이메일로 동의 내용을 보내고 회신을 운영자가 검토·승인하는 방식이다. 동의 전 어린이의 닉네임·이메일·비밀번호는 수집하지 않는다. 실제 법정대리인 확인과 증빙 관리 절차는 운영 활성화 전에 갖추며, 외부 유료 본인확인 업체를 선택하거나 계약하지 않는다. 어린이 계정은 1차에서 커뮤니티 읽기만 허용한다. 공개 글·댓글 작성의 향후 허용 여부, 결제와 대회 참여는 별도로 정한다.

개인정보 처리에 법에 따른 동의가 필요한 경우, 만 14세 미만 아동은 법정대리인의 동의를 받고 실제 동의 여부도 확인해야 한다는 [개인정보 보호법 제22조의2](https://law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1020398523)를 설계 근거로 삼는다(2026-10-16 확인). 단순 체크박스, 이메일 도착·링크 클릭만으로 동의나 본인 확인이 완료되었다고 판단하지 않는다. 운영자의 회신 검토와 법정대리인 확인 절차를 함께 갖춰야 한다.

첫 화면에는 ‘바로 시작’과 ‘로그인’ 진입을 마련한다. 플레이를 가입창으로 강제로 끊지 않고, 몇 판 체험한 뒤 기록 보관의 이점을 안내하는 방향이다. 안내의 정확한 시점·횟수와 문구는 따로 정하며, 실제 제공하는 저장 기능의 범위를 넘어서 약속하지 않는다.

## 2. 현재 상태와 목표의 차이

아래 기술 현황은 2026-10-16에 확인한 저장소 코드와 문서 기준이다. 운영 서버의 배포 상태나 실제 회원 데이터를 조회했다는 뜻은 아니다. 별도로 사용자가 두 게임 모두 현재 실제 이용자 0명이라고 확인했다. 따라서 기존 게임 이용자의 계정 승계·진행도·구매 내역 이전과 전환 유예는 1차 범위에서 제외한다.

이 확인을 커뮤니티 회원도 0명이라는 뜻으로 확대하거나 기존 데이터 삭제 허가로 해석하지 않는다. 기존 커뮤니티 회원이 있다면 회원 식별자와 글·댓글의 작성자 관계를 보존한다.

| 영역 | 현재 확인한 상태 | 목표 |
| --- | --- | --- |
| 사이트·커뮤니티 | 사이트는 GitHub Pages, 커뮤니티는 전용 Fly 서버로 연결하는 구성이다. 기존 커뮤니티의 이메일·닉네임·비밀번호 계정을 `/account/` 사이트 공통 화면에서 이용한다. 게임 계정 연결은 아직 없다. | 기존 커뮤니티 회원을 보존하면서 두 게임에서 사용할 공통 회원 체계를 연결한다. |

1차 코드는 보호자 동의 신청의 승인 상태를 서버에서 확인한 뒤 만 14세 미만 가입을 허용한다. 메일 발송·회신 수신이 연결되지 않은 환경에서는 어린이 가입이 열리지 않는다. 운영 배포와 실제 법정대리인 확인 절차 검토가 완료되었다는 뜻은 아니다.

이번 결정은 경국지계의 기존 게스트 시작 방향과 양립한다. 실제 두 게임의 인증과 기록 연결은 이번 1차 사이트 계정 구현에 포함하지 않으며, 어떤 기록부터 저장·연결할지는 후속 기획에서 정한다.

공통 회원 식별자와 각 게임의 플레이어 식별자를 연결한다. 닉네임이나 이메일 주소를 회원 연결의 기준 키로 삼지 않는다. 계정이 같아도 두 게임의 재화·랭크·구매 내역은 합치지 않는다. 위 표는 데이터의 담당 영역을 구분한 것으로, 모든 항목의 서버 저장을 1차에 구현한다는 뜻은 아니다.

초기 연결안은 회원 한 명에게 게임별 프로필 하나를 연결하는 구조다. 신규 게스트가 이미 같은 게임의 기록이 있는 공통 계정에 로그인할 수도 있으므로, 이때의 선택·충돌 처리 방법은 구현 전에 정한다. 게스트 기록과 계정 기록을 자동으로 합치거나 덮어쓰지 않는다.

## 4. 가입과 게임 진입 흐름

1. 사용자가 사이트의 게임 시작 버튼, 게임 주소 또는 앱으로 진입한다.
2. 게임 첫 화면에서 ‘바로 시작’과 ‘로그인’으로 진입할 수 있게 한다. 유효한 게임용 로그인 상태가 있으면 연결된 게임 프로필을 이용한다.
3. 로그인하지 않은 이용자가 ‘바로 시작’을 선택하면 허용된 게스트 플레이로 들어간다. 로그인 상태가 없다는 이유만으로 가입창으로 보내지 않는다.
4. 몇 판 체험 후 플레이를 강제로 끊지 않는 방식으로 기록 보관의 이점을 안내한다. 이용자가 기록 연결이나 회원 기능을 선택하면 공통 가입·로그인으로 연결한다. 첫 화면의 ‘로그인’에서도 같은 인증 흐름을 시작한다.
5. 기존 공통 회원은 로그인하고, 신규 이용자는 공통 계정을 만든다. 만 14세 미만은 법정대리인 동의 절차를 거쳐 가입하도록 설계한다. 인증 결과를 해당 게임 서버에서 확인한 뒤 원래 시작한 게임으로 복귀한다. 유효한 공통 로그인 상태의 재사용 범위는 세션 정책에서 정한다.
6. 신규 가입자는 방금 게스트로 플레이한 기록을 계정에 연결해 이어 한다. 이미 게임 프로필이 있는 계정에 로그인했다면 확정할 충돌 처리 절차를 거친다. 인증이나 연결 실패를 이유로 게스트 기록 또는 계정 기록을 먼저 지우지 않는다.

다른 게임에서도 같은 회원 계정을 사용한다. 기기·브라우저·앱이 바뀌거나 세션이 만료되면 다시 인증할 수 있으며, 모든 환경에서 무조건 자동 로그인된다고 약속하지 않는다.

사이트의 게임 소개 열람과 게임 실행은 계속 구분한다. 기존 ‘START를 누르기 전에 게임이나 게임 자원을 불러오지 않는다’는 원칙을 유지한다. 로그인 화면의 구체적인 외형·위치·버튼 배치는 별도 화면 기획에서 정한다.

## 5. 공통 인증의 경계

공통 계정을 사용해도 각 게임 서버는 로그인 결과와 해당 게임의 회원 기능에 대한 접근 권한을 확인해야 한다. 사이트 버튼을 숨기거나 브라우저에 로그인 표시를 저장하는 것만으로 랭크·기록 연결 등 회원 기능의 권한을 처리하지 않는다. 게스트 플레이와 회원 기능의 권한을 구분한다.

공통 인증 서비스가 회원을 확인하고, 게임이 자신에게 발급된 인증 결과를 검증한 뒤 게임용 세션을 만드는 구성을 기본안으로 둔다. 웹과 앱을 지원하는 표준 인증 방식인 OpenID Connect 등을 후보로 검토한다. 현재 Better Auth 구성에서 필요한 기능을 어떻게 제공할지는 별도 조사하며 제품·플러그인·요금제는 이 문서에서 확정하지 않는다.

인증 복귀 주소와 대상 게임을 제한하고, 만료·재사용·다른 게임에 대한 인증 결과를 구분한다. 공통 로그인 비밀값이나 비밀번호를 각 게임에 복사하지 않는다. 현재 Fly 커뮤니티 주소와 게임 주소는 출처가 다르므로 기존 쿠키를 그대로 공유하면 된다고 가정하지 않는다.

계정 복구, 전체 기기 로그아웃, 게임별 제재와 공통 계정 제재, 게임 데이터 삭제와 전체 회원 탈퇴의 범위는 따로 정한다. 한 게임의 탈퇴·제재가 다른 게임과 커뮤니티에 어떤 영향을 주는지 사용자에게 명확히 안내할 수 있어야 한다.

## 6. 신규 게스트 기록 연결과 커뮤니티 데이터 보존

- 과거 게임 이용자를 공통 계정으로 옮기는 작업은 1차 범위에 넣지 않는다. 앞으로 유입되는 신규 이용자가 게스트 플레이 후 가입하여 같은 기록을 이어가는 흐름은 필요한 기능으로 남긴다.
- 게스트 기록을 연결할 때 공통 회원 인증과 해당 게스트 기록을 연결할 권한을 확인한다. 게임별 확인 수단·연결 시점·대상 기록은 구현 전에 정한다.
- 이미 다른 회원에게 연결된 기록은 연결을 거절하고 충돌 안내를 제공한다. 기존 연결을 조용히 교체하지 않는다.
- 로그인한 계정에 이미 같은 게임의 기록이 있다면 무조건 합치거나 덮어쓰지 않는다. 선택 절차가 확정되기 전에는 어느 쪽 기록도 삭제하지 않는다.
- 연결 성공을 이유로 기록을 초기화하거나 보상을 중복 지급하지 않는다. 연결 전후의 대응 관계와 실패 시 재시도 방법을 검증한다.
- 기존 커뮤니티 회원이 있다면 식별자와 글·댓글 작성자 관계를 보존한다. 공통 회원 식별자가 새로 필요하면 기존 회원과의 대응 관계를 남긴다.
- 닉네임이나 이메일 주소가 같다는 이유만으로 계정을 자동 연결하지 않는다. 현재 커뮤니티 이메일은 확인되지 않은 상태다.

이메일 인증·비밀번호 재설정은 1차 공통 회원 기능으로 구현하며 실제 운영 메일 연결은 배포 준비 항목으로 남긴다. 소셜 로그인을 제공할지와 어떤 공급자를 사용할지는 미확정이며, 기존 게임 코드에 로그인 수단이 있다는 이유로 모두 채택하지 않는다.

## 7. 대회와 경품의 후속 연계

앞선 대화에서는 한국시간 매일 밤 10시 토너먼트, 참가 인원에 맞춘 대진표, 순위 보상, 우승자 커피 쿠폰을 아이디어로 논의했다. 공통 계정에서는 게임별 대회 신청·우승 기록·경품 수령 내역을 한 회원에게 연결해 사이트에서 모아 볼 수 있다.

대회 개최 여부, 참가 최소·최대 인원, 진행 방식, 보상 종류·금액·지급 조건·예산은 아직 확정하지 않았다. 공통 계정 반영으로 대회를 개설하거나 쿠폰을 구매·발송하지 않는다. 공통 계정 한 개가 실제 사람 한 명을 보장하지 않으므로 중복 출전·수령 방지 정책도 대회 기획에서 별도로 정한다.

## 8. 다음 기획 범위와 미확정 항목

사이트 공통 계정 1차 구현 후에는 두 게임의 인증·저장 구조를 조사하고 아래 후속 결정 항목을 정리한다. 사용자 구현 요청에 따라 사이트 기능은 구현하지만 공개 배포는 별도 요청 때 진행한다.

1. 만 14세 미만의 법정대리인 회신 확인과 증빙 보관·삭제를 위한 운영 절차, 메일 업체·요금·개인정보처리방침, 보호자 관리 화면. 어린이 계정은 1차에서 커뮤니티 읽기만 허용하고 공개 글·댓글 작성의 향후 허용과 결제·대회 참여 범위는 따로 정한다. 어린이 가입은 보호자 동의 승인 없이는 서버에서 거절하며 실제 메일·회신 수신 연결과 운영 절차 준비 전에는 활성화하지 않는다. 게임 서비스의 청소년 가입 동의 적용 범위는 [게임산업진흥에 관한 법률 제12조의3](https://www.law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1025570837)과 [시행령 제8조의3](https://law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lspttninfSeq=56576)의 대상·예외를 확인해 세부 설계에서 정하며, 사업자·게임별 적용이나 면제 여부는 이번에 판단하지 않는다.
2. 로그인 수단, 이메일 인증·복구 메일 제공 방식과 기존 커뮤니티 회원을 공통 회원으로 확장하는 방법.
3. 게임별 게스트 저장 항목·보존 범위, 가입 후 연결할 기록, 이미 기록이 있는 계정과의 충돌 처리, 클라우드 저장 및 다른 기기 이어하기의 제공 범위.
4. 경국지계 일반 체험의 구체적 범위와 일반 실시간 PvP의 게스트 허용 여부, 가입 안내의 시점·횟수·문구.
5. 공통 인증 서비스의 주소·운영 위치, 웹·앱 복귀 방식, 로그인 유지와 만료, 게임별 세션·공통 로그아웃 처리.
6. 공통 닉네임과 게임별 닉네임의 관계, 게임별 제재·탈퇴와 전체 계정 제재·탈퇴의 범위.
7. 인증 서버 장애·만료 때의 게스트 진입·회원 기능·진행 중 경기 처리.

운영 준비로는 실제 배포 상태와 문서를 맞추고, 계정 데이터를 변경하기 전에 백업·복구 시험을 수행할 계획을 세운다. 게임위 문의, 사업자 정보, Play 등록정보 준비는 별도 운영 항목으로 유지한다. 코인·결제·대회·경품과 사진 첨부는 이번 게스트 진입 결정으로 구현 범위에 추가하지 않는다.

향후 구현 검수에서는 다음을 확인한다. 아래 목록은 검수 기준이며 현재 통과 기록이 아니다.

- 허용된 기본 플레이와 체험은 가입 없이 시작할 수 있고, 가입 안내가 진행 중인 플레이를 강제로 끊지 않는가.
- 만 14세 미만 가입은 확정한 법정대리인 동의·확인 절차를 거치는가. 어린이 계정의 기능 권한이 별도로 정한 연령별 이용 범위와 일치하는가.
- 사이트·게임 직접 진입·지원하는 모바일 앱에서 공통 가입·로그인 후 원래 게임으로 복귀하는가.
- 신규 가입 후 방금 플레이한 게스트 기록을 이어가며, 다른 회원의 기록에 접근하거나 연결하지 못하는가.
- 이미 기록이 있는 계정과 충돌하거나 연결에 실패해도 기록이 자동으로 합쳐지거나 덮어써지거나 삭제되지 않는가.
- 같은 회원의 두 게임 프로필이 구분되고, 잘못된 게임용 인증 결과·로그아웃·만료 뒤의 접근이 처리되는가.
- 커뮤니티 회원과 글·댓글이 있다면 공통 계정 확장 후 작성자 관계가 유지되는가.
- START 전 게임·게임 자원을 미리 불러오지 않는가. 다른 기기 이어하기를 구현한다면 확정된 저장 범위대로 복원되는가.

## 9. 사이트 계정 1차 구현 범위

- `/account/`: 로그인, 나이 선택, 만 14세 이상 가입, 보호자 동의 신청·상태 확인·취소·승인 뒤 어린이 가입, 이메일 확인·재발송, 비밀번호 재설정, 로그아웃.
- 새 가입은 이메일 확인을 마쳐야 로그인할 수 있다. 기존 커뮤니티 회원의 식별자·작성자 관계와 로그인은 유지한다. 기존 회원의 연령을 임의로 추정하지 않는다.
- 만 14세 미만은 보호자 성명·이메일만 먼저 받고 동의 내용에 대한 회신을 운영자가 검토한다. 승인된 신청 브라우저에서 한 번만 자녀 계정을 만들 수 있다. 자녀 로그인용 이메일은 아직 가입되지 않은 보호자 이메일을 사용할 수 있으나 같은 이메일이라는 이유로 기존 계정과 자동 연결하지 않는다.
- 동의 대기 상태는 HttpOnly 쿠키로 이어지고 화면에서는 버튼으로 확인한다. 반복 폴링은 하지 않는다. 어린이 계정은 서버와 화면의 `canWriteCommunity` 권한으로 글·댓글 작성을 막는다.
- 메일 확인·복구 인증값은 해시 링크로 전달하고 페이지 진입 즉시 주소에서 지워 메모리에서만 처리한다. 메일 확인은 사용자의 버튼 POST 요청으로만 실행하여 링크를 미리 여는 메일 검사기로 인해 소모되지 않게 한다. 계정 화면에는 외부 통계 스크립트가 없다.
- 사이트와 계정 화면의 돌아가기 링크는 알려진 게임 소개·커뮤니티만 사용한다. 외부 주소를 받는 임의 복귀 URL은 제공하지 않는다. START 전 게임 자원을 미리 요청하지 않는다.
- 보호자 동의 철회는 운영자 처리로 어린이 세션을 무효화하고 이후 로그인을 차단한다. 자동 회원 탈퇴 화면·유료 본인확인·소셜 로그인·게임 서버 연결·게스트 기록 연결·클라우드 저장·결제·대회는 이번 구현 범위가 아니다.

운영 활성화 전 메일 발송과 보호자 회신 수신 설정, 법정대리인 확인과 증빙 보관·삭제 절차, 개인정보처리방침의 실제 발송업체와 국외 전송 정보를 갖춰야 한다. 메일 미설정 상태에서는 새 가입·메일 기능이 준비 중으로 표시되고 기존 로그인은 유지된다. 개인정보처리방침 변경본은 공개 전 개정안이며 이번 작업에서 배포하지 않는다.
