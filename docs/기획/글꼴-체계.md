# 사이트 글꼴 체계

2026-10-18 사용자가 조율자의 추천안대로 확정했다. 사이트 전체 글꼴을 역할 세 가지로 통일하고, 한 파일에서만 정의하며, 검사로 강제한다. 2026-10-18 사용자 요청으로 구현·공개 배포했다([배포 기록](../커뮤니티-배포.md)).

## 1. 배경

2026-10-18 점검 결과, 페이지마다 글꼴을 따로 정하고 있었다.

- 영문 로고 “GRACEKIN GAMES”: 홈은 Cinzel, 계정·커뮤니티·게임 소개 페이지는 Georgia라 서로 다르게 보인다.
- 한글 제목: 홈과 경국지계 소개는 Noto Serif KR을 불러오지만, 커뮤니티는 `"Iowan Old Style","Noto Serif KR","AppleMyungjo"`를 불러오지 않고 지정해 기기마다 맥은 애플명조, 윈도우는 바탕 계열로 보인다. 슬라임 라인 소개는 `AppleMyungjo`·`Batang`과 불러오지 않은 `Nanum Pen Script`를 쓴다.
- 본문: 같은 기기 고딕 목록(`system-ui,-apple-system,"Apple SD Gothic Neo","Noto Sans KR",sans-serif`)이 `account.css`·`community.css`·`account-header.css`·`race.css`·`privacy.css` 다섯 곳에 따로 복사돼 있고, Noto Sans KR은 실제로 불러오지 않는다. 슬라임 라인 소개는 `"Apple SD Gothic Neo","Malgun Gothic"`을 쓴다.

## 2. 역할 세 가지

| 변수 | 글꼴 | 쓰는 곳 | 굵기 |
| --- | --- | --- | --- |
| `--font-brand` | Cinzel | 영문 로고·브랜드명만 | 400, 500 |
| `--font-display` | Noto Serif KR | 페이지·섹션·카드 제목, 경주 안내판·결과 제목, 경국지계 명조 본문 예외 | 400(경국지계 본문 예외), 500, 600 |
| `--font-body` | Noto Sans KR | 본문, 버튼, 입력칸, 표, 상단 계정 표시, 티켓 창 | 400, 500, 600 |

- 세 역할 글꼴과 손글씨 예외를 공용 `fonts.css`의 `@import` 한 곳에서 `display=swap`으로 함께 불러온다. 이미 쓰는 업체라 새 외부 처리자가 늘지 않으며, 한글은 필요한 글자 조각만 받는다.
- 대체 글꼴 순서는 변수 안에만 둔다. 본문 대체: `"Noto Sans KR",system-ui,-apple-system,"Apple SD Gothic Neo","Malgun Gothic",sans-serif`. 제목 대체: `"Noto Serif KR","AppleMyungjo","Batang",serif`. 로고 대체: `"Cinzel",Georgia,serif`.
- 위 표에 없는 굵기는 쓰지 않는다. 필요하면 이 문서를 먼저 고친다.

## 3. 공용 파일 하나

- `assets/shared/fonts.css` 한 파일에 글꼴 불러오기와 세 역할 변수, 등록된 손글씨 예외 변수 `--font-hand`를 둔다. 페이지는 다른 스타일시트보다 먼저 `/assets/shared/fonts.css`를 불러온다. 구글 폰트 주소의 스타일시트 `<link>`는 없애고, 필요하면 `fonts.googleapis.com`·`fonts.gstatic.com`의 `preconnect`만 둔다.
- 대상: 대표 홈, 계정·운영 화면, 커뮤니티, 개인정보처리방침·이용약관, 비공개 버그 제보, 게임 소개 페이지 두 곳.
- 각 CSS는 글꼴 이름을 직접 쓰지 않고 `var(--font-…)`만 쓴다. `inherit`·`initial`은 허용한다. 기존 `font` 단축 속성의 크기·행간은 개별 속성으로 풀어 보존한다.
- 로고는 모든 페이지에서 `--font-brand`로 같게 보이게 한다.
- 새 파일이므로 `.dockerignore` 명시 허용 목록에 추가한다. GitHub Pages와 커뮤니티 서버가 같은 파일을 제공한다.

## 4. 게임 소개 페이지 예외

게임의 개성을 살리는 장식 글꼴은 허용한다. 다만 아래 조건을 지킨다.

- 로고(`--font-brand`)와 버튼·입력칸·안내 문장 같은 기능 글자는 공용 변수를 쓴다.
- 장식 글꼴은 이 문서의 예외 목록에 등록하고, 실제로 불러온다. 기기에 있을 때만 보이는 글꼴을 지정하지 않는다.
- 손글씨 예외는 공용 `fonts.css`의 `--font-hand`로만 정의한다. 사용은 `games/slimeline/`와 `assets/community/community.css`로 제한하고 5절 4번 검사로 강제한다. 커뮤니티에서는 슬라임 라인 테마에만 적용한다.

| 페이지 | 예외 | 용도 | 처리 |
| --- | --- | --- | --- |
| 슬라임 라인 소개·커뮤니티의 슬라임 라인 테마 | Nanum Pen Script (`--font-hand`, 400) | 소개의 첫 화면 손글씨 문구(`.hero-tagline`)와 해당 커뮤니티 테마 | 공용 `@import`에서 불러온다. 소개의 나머지 애플명조·바탕 제목은 `--font-display`로 바꾼다 |
| 경국지계 소개 | Noto Serif KR 본문 | 역사 분위기의 명조 본문 | 현행 명조를 유지하고 `--font-display`를 직접 참조한다. 본문용 400 굵기를 공용 불러오기에 포함한다. 기능 링크·버튼은 `--font-body`를 쓴다 |
| 슬라임 레이스(대표 홈) | Jua(`RaceJua`, OFL, 저장소 내 `assets/slime-race/art/clay/Jua-Regular.woff2`) | 점토 경기장 간판·결과판의 둥근 게임 글씨 | 2026-10-18 점토 테마 배포에서 추가됐다. 통합 때 `@font-face`를 `fonts.css`로 옮기고 `--font-race` 변수로만 쓰게 했다. 검사기는 `--font-race`를 `assets/slime-race/race.css`에서만 허용한다 |

게임 본체(별도 저장소)의 글꼴은 이 문서의 범위가 아니다.

## 5. 검사로 강제

`scripts/verify_site.py`에 다음 규칙을 추가해 위반 시 검사를 실패시킨다.

1. 3절 대상 페이지는 모두 `/assets/shared/fonts.css`를 첫 스타일시트로 불러와야 한다.
2. `fonts.css` 밖의 CSS·HTML `<style>`·`style=`에서 `font-family`·`font` 단축 속성에 글꼴 이름을 직접 쓰면 실패한다(`var(--font-…)`, `inherit`, `initial`만 허용). 단축 속성의 크기·행간은 허용하되 역할 변수 뒤에 직접 쓴 대체 글꼴도 거부한다.
3. 구글 폰트 요청 주소는 `fonts.css`의 `@import` 한 곳에서만 허용한다. HTML의 두 폰트 출처 `preconnect`는 허용한다.
4. `--font-hand`는 `games/slimeline/`와 `assets/community/community.css`에서만 쓸 수 있다. 공용 파일의 변수 정의는 허용한다.
5. 커뮤니티 개편 통합 전에는 `PENDING_FONT_MIGRATION`의 `community/index.html`·`assets/community/community.css`에만 1·2·3번 검사를 임시 면제한다. 조율자가 통합할 때 목록을 비운다. 4번 사용처 제한은 면제하지 않는다.

규칙 위반을 고치기 어려운 경우에는 검사를 끄지 말고 이 문서의 예외 목록을 먼저 갱신한다.

## 6. 구현·통합 순서

1. `assets/shared/fonts.css` 작성과 `.dockerignore` 등록
2. 홈·계정·커뮤니티·방침·약관·버그 제보·운영 화면을 공용 변수로 교체
3. 게임 소개 페이지 두 곳을 4절 예외 규칙에 맞춰 정리
4. `verify_site.py` 규칙 추가와 회귀 시험
5. 1,440·390·320px 화면 비교(로고·제목·본문 줄바꿈과 가로 넘침), 맥·윈도우 계열 대체 글꼴 확인
6. 공개 배포는 사용자 요청 시 Pages와 커뮤니티 서버에 함께 반영

## 7. 구현 상태(2026-10-18 공개 배포)

- `formars0309-cloud/font-system-implementation` 하위 구현 브랜치의 변경을 조율자가 검수해 `formars0309-cloud/font-system` 작업 브랜치에 통합했다. 커밋은 이 작업 브랜치에만 남긴다.
- 커뮤니티 개편의 세 파일과 공용 계정 헤더 JavaScript는 수정하지 않았다. 커뮤니티의 임시 검사 제외는 통합 시 제거한다.
- 공개 배포·푸시·main 병합은 진행하지 않았다. 전체 시험과 화면 비교 결과는 [글꼴 체계 검증 기록](../글꼴-체계-검증.md)에 기록했다.
