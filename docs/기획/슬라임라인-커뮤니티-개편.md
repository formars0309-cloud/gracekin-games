# 슬라임 라인 커뮤니티 개편 기획

2026-10-18 Slime 세션에서 인계받았다. 사용자는 슬라임 라인 커뮤니티가 “신경을 안 써서 완전 허접한 상태”라며 수정·구현을 원했다. 같은 날 조율자의 추천안대로 방향을 확정했다. **구현은 사용자가 명시한 뒤 진행한다.** [글꼴 체계](글꼴-체계.md)를 이 개편과 함께 적용한다.

## 1. 현재 문제

2026-10-18 운영 화면(`/community/?game=slimeline`)을 슬라임 라인 소개 페이지·경국지계 커뮤니티와 1,440px로 비교했다.

1. **소개 페이지와 단절.** 소개 페이지는 밤 숲 그림(`assets/slimeline/hero.webp`), 분홍·하늘·노랑·연두 슬라임, 손글씨 제목 그림(`title.png`), 밤하늘 남색·크림·라벤더 색으로 개성이 뚜렷하다. 그 페이지의 “커뮤니티” 버튼을 누르면 그림 없는 기본 보라 틀로 넘어간다. 경국지계는 커뮤니티에도 한지 톤 전용 테마가 있으나 슬라임 라인은 기본 테마 그대로다.
2. **빈 장식.** 큰 제목 오른쪽 장식이 거의 보이지 않는 어두운 덩어리와 작은 도형이라 비어 보인다.
3. **빈 게시판.** 자유게시판 “글 0개”인데 목록 아래가 비어 있고 첫 글 유도가 없다.
4. **이름 불일치.** 소개 페이지는 ‘새 소식’, ‘우리들의 이야기 — 자유 이야기 · 공략 나누기 · 작품 자랑’인데 커뮤니티는 ‘자유게시판 · 공략·팁 · 갤러리 · 공지사항’이다.
5. **그림 없는 갤러리.** 게시글은 글만 쓸 수 있어 ‘갤러리’에 그림을 올릴 수 없다.
6. **흐린 위계.** SLIMELINE·COMMUNITY·A LITTLE NOTE 같은 영문 작은 제목과 회색 작은 글씨가 많다. 로그인 상태에서는 상단 계정 표시와 “말랑이님, 반가워요” 줄이 겹친다.
7. **글꼴 혼재.** 로고는 Georgia, 제목은 기기 명조(맥 애플명조·윈도우 바탕 계열)로 기기마다 다르게 보인다.

## 2. 방향: 게임 세계를 이어 붙인다

소개 페이지의 그림·색·글꼴을 커뮤니티로 그대로 이어, 소개 페이지에서 넘어와도 같은 세계로 느껴지게 한다. 경국지계 커뮤니티는 기존 테마를 유지하고 글꼴 체계만 함께 적용한다.

### 2-1. 슬라임 라인 전용 테마

- `data-game="slimeline"` 전용 색 변수를 만든다. 소개 페이지 값(`--night:#101728`, `--cream:#f5e3d0`, `--lavender:#8e78db`, `--muted:#b9b4be`, `--line:#6c6378`)을 기준으로 배경·카드·강조·보조 글자색을 정한다.
- 본문 대비는 WCAG AA(본문 4.5:1, 큰 글씨 3:1) 이상으로 맞춘다.
- 경국지계 테마 변수와 섞이지 않게 게임별 블록으로 분리한다.

### 2-2. 첫 화면

- 소개 페이지 밤 숲 그림을 넓은 띠로 쓰고, 그 위에 `title.png`(슬라임 라인 손글씨 로고)와 “커뮤니티” 제목, 한 줄 소개 “작은 슬라임의 길에서 만난 이야기를 나누어요”를 올린다.
- 어두운 덩어리·도형 장식과 영문 소제목 `SLIMELINE`을 없앤다.
- 그림 위 글자는 어두운 그라데이션으로 대비를 확보한다. 390·320px에서는 슬라임 무리가 잘리지 않도록 그림 위치를 오른쪽 아래 기준으로 맞추고 높이를 줄인다.
- 게임 소개 페이지로 돌아가는 링크와 “게임 START”를 첫 화면에 둔다.

### 2-3. 게시판 이름과 탭

화면에 보이는 이름만 소개 페이지와 맞춘다. 서버의 게시판 값(`free`·`guide`·`gallery`·`notice`)과 주소는 바꾸지 않는다.

| 서버 값 | 현재 | 변경 | 아이콘 |
| --- | --- | --- | --- |
| `free` | 자유게시판 | 자유 이야기 | 말풍선 |
| `guide` | 공략·팁 | 공략 나누기 | 책 |
| `gallery` | 갤러리 | 작품 자랑 | 카메라 |
| `notice` | 공지사항 | 새 소식 | 새싹 |

- 탭은 소개 페이지 ‘우리들의 이야기’ 카드와 같은 아이콘을 쓰는 둥근 탭으로 바꾼다. 모바일에서는 가로로 넘긴다.
- 각 게시판 소개 문장도 새 이름에 맞춰 다시 쓴다.

### 2-4. 빈 게시판과 첫 글 유도

- 글이 없을 때 슬라임 그림(`assets/slime-front.png` 또는 레이스 슬라임 그림)과 함께 게시판별 문장을 보여 준다. 예: 자유 이야기 “아직 조용해요. 첫 이야기를 남겨 주세요.”
- 글쓰기 가능한 회원에게는 “글쓰기” 버튼과 “글을 쓰면 24시간 뒤 500 그레인이 적립돼요”를 함께 보여 준다. 보상 자격이 없는 회원(미인증·어린이·정지)에게는 보상 문장을 숨긴다. 수치는 서버 공개 설정 `grainRewardPolicy`에서 읽는다.
- 비로그인 사용자에게는 로그인·회원가입 버튼을 보여 준다.
- 검색 결과가 없을 때와 게시판이 비었을 때 문장을 구분한다.

### 2-5. 계정 줄 정리

- 로그인 상태에서는 상단 계정 표시(닉네임·그레인)가 이미 있으므로 “○○님, 반가워요” 줄을 없애고, 로그아웃은 상단 계정 메뉴로 옮긴다.
- 비로그인 상태에서는 “로그인하면 글·댓글을 남기고 그레인을 받을 수 있어요” 한 줄과 로그인·회원가입 버튼만 둔다.
- “게임 계정 연결은 준비 중” 안내는 오른쪽 안내 칸으로 옮긴다.

### 2-6. 오른쪽 안내 칸

‘A LITTLE NOTE’ 장식 카드를 쓸모 있는 안내로 바꾼다.

- 그레인 받는 방법 요약(출석 300, 글 500, 댓글 100, 자세히 보기 → `/account/`의 지급표). 수치는 `grainRewardPolicy`에서 읽는다.
- 알려진 문제 수와 비공개 버그 제보 링크.
- 의견 보내기, 이용약관, 게임 계정 연결 준비 안내.
- 모바일에서는 목록 아래로 내린다.

### 2-7. 위계와 글꼴

- 영문 장식 소제목(`COMMUNITY`, `A LITTLE NOTE`)을 없애거나 한글 제목으로 바꾼다.
- 작은 회색 글씨는 13px 미만을 쓰지 않고 대비 기준을 지킨다.
- [글꼴 체계](글꼴-체계.md)에 따라 로고 Cinzel, 제목 Noto Serif KR, 본문 Noto Sans KR을 공용 파일로 적용한다. 손글씨는 소개 페이지 예외(Nanum Pen Script)를 커뮤니티 첫 화면 한 줄 소개에도 허용하도록 예외 목록에 추가한다.

### 2-8. 작품 자랑(갤러리)

1단계에서는 그림 올리기를 넣지 않는다. 작품 자랑 게시판 상단에 “그림 올리기는 준비 중이에요. 지금은 글로 소개해 주세요.”를 안내한다.

## 3. 2단계: 작품 자랑 그림 올리기 (이번 범위 아님)

사용자 결정으로 미룬다. 진행할 때 다음을 먼저 정한다.

- 저장 위치(현재 Fly 1GB 볼륨은 DB 전용), 파일 형식·용량·개수 제한, 서버에서 다시 인코딩해 위치정보(EXIF) 제거
- 부적절한 그림 신고·숨김, 운영자 화면 연동
- 개인정보처리방침·이용약관 갱신, 저작권 안내

## 4. 범위와 영향

- 수정 파일: `community/index.html`, `assets/community/community.css`, `assets/community/community.js`, 새 `assets/shared/fonts.css`, 글꼴 체계 대상 페이지의 CSS, `scripts/verify_site.py`, `.dockerignore`.
- 서버 API·DB 변경 없음. 게시판 값·주소·게시글·보상·신고 기능은 그대로다.
- 경국지계 커뮤니티: 게시판 이름·테마 변경 없음. 글꼴 체계와 공용 구조(계정 줄·안내 칸·빈 상태) 변경은 함께 적용되므로 화면 회귀를 확인한다.
- 그림은 저장소의 기존 자산(`assets/slimeline/hero.webp`, `title.png`, `assets/slime-front.png`, `assets/slime-race/art/slime*.png`)만 쓴다. 커뮤니티 서버가 제공하도록 `.dockerignore` 허용 목록을 확인한다.

## 5. 완료 기준

1. 슬라임 라인 소개 페이지 → 커뮤니티 이동 시 같은 그림·색·로고가 이어진다.
2. 1,440·390·320px에서 첫 화면 그림이 잘리지 않고 가로 넘침·콘솔 오류가 없다.
3. 빈 게시판·검색 결과 없음·비로그인·로그인·보상 미자격 상태별 문장이 맞게 나온다.
4. 게시판 이름 4개가 소개 페이지와 같고, 기존 주소(`?board=free` 등)가 그대로 동작한다.
5. 경국지계 커뮤니티가 기존 테마로 정상 동작한다(같은 세 폭 비교).
6. 글꼴 체계 검사 규칙과 기존 `npm test`, `python3 scripts/verify_site.py`, `git diff --check`가 통과한다.
7. 본문 대비 4.5:1 이상, 키보드로 탭·버튼 이동 가능, `prefers-reduced-motion`에서 장식 움직임 없음.

## 6. 구현 순서 제안 (사용자가 명시한 뒤)

1. 공용 글꼴 파일과 변수(글꼴 체계 1단계)
2. 커뮤니티 공용 구조 정리: 계정 줄, 안내 칸, 빈 상태, 영문 소제목 제거
3. 슬라임 라인 전용 테마·첫 화면·탭·게시판 이름
4. 나머지 페이지 글꼴 교체와 검사 규칙
5. 세 폭 화면 비교 검수(슬라임 라인·경국지계 각각, 로그인·비로그인)
6. 공개 배포는 사용자 요청 시 Pages와 커뮤니티 서버에 함께 반영
