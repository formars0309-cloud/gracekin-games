# 슬라임 레이스 기획 정본

2026-10-17 확정 요구사항을 기록한다. 최초 작업은 사이트 구현까지 진행했으며 공개 배포는 하지 않았다. 이후 사용자의 ‘그레인을 무료 화폐로만 사용’하는 사이트 반영 요청을 이 정본에 반영했다. 사용자가 공개 배포를 명시적으로 요청한 뒤 같은 날 소스 `863f9e2`를 Fly·GitHub Pages에 공개했다. 관람·응원은 제공하고 본인확인 서비스 연동 전 구매 잠금을 유지한다. 격리 시험과 실제 공개 검수는 [검증 기록](../슬라임-레이스-검증.md)에서 구분한다.

## 화면과 참가 선수

홈 첫 화면에는 따뜻한 숲 분위기의 큰 경주장을 배치한다. 기존 게임 소개와 게임 카드는 아래에서 계속 이용한다. 경주 관람과 응원은 누구나 가능하며 응원은 경기 결과에 영향을 주지 않는다.

기본 화면은 관람에 집중한다. `출전 정보 · 티켓 구매` 단일 버튼을 누르면 PC에서는 팝업, 모바일에서는 아래에서 올라오는 시트를 연다. 선수 정보와 티켓 구매·수정·취소를 같은 창에서 처리한다.

선수마다 `기초체력`, `주행 성향`, `이번 경기 컨디션`을 같은 순서로 비교한다. PC에서는 한 줄, 모바일에서는 세 열로 표시한다.

- 기초체력 등급: S·A·B·C.
- 주행 성향: 초반질주형·꾸준형·후반추격형·순간가속형·변칙형. 시안의 띄어쓰기 차이는 같은 성향을 뜻한다.
- 컨디션: 매우나쁨·나쁨·보통·좋음·매우좋음. 매 경기 새로 정한다.
- 최근 경기 기록과 원금 포함 배당을 확인할 수 있다. 선수의 고정 등급과 회차별 컨디션은 구분한다.

10명 기본 등급은 이전 시안을 보존한다. 사용자가 수락한 다섯 성향을 실제 경기에 사용하도록 반짝을 순간가속형, 밤별을 변칙형으로 확장했다. 나머지 성향은 보존한다. 성향은 연출 차이를 만들며 기초체력이나 총 기대 실력을 추가로 바꾸지 않는다. 고정 선수 정보를 서버와 화면에서 다르게 관리하지 않는다.

전체 10명 중 매 경기 5명이 출전한다. 최근 출전 횟수가 적은 선수가 뽑힐 가능성을 높인다. 전원이 같은 확률로 출전하거나 등급만으로 출전 선수를 고정하지 않는다.

## 공동 경기와 결과

모든 이용자가 같은 회차를 관람하는 공동 경기다. 24시간, 10분 간격을 목표로 한다. 각 회차의 시간 구간은 서버 시간을 기준으로 한다.

| 시작 후 시간 | 구간 | 티켓 |
| --- | --- | --- |
| 0초 이상 500초 미만 | 판매 8분 20초 | 구매·수정·취소 가능 |
| 500초 이상 510초 미만 | 마감 카운트다운 10초 | 구매·수정·취소 불가 |
| 510초 이상 570초 미만 | 경주 60초 | 구매·수정·취소 불가 |
| 570초 이상 600초 미만 | 결과 30초 | 구매·수정·취소 불가 |

마감 후 서버가 기본 체력과 이번 회차 컨디션에 따른 확률로 승자를 추첨한다. 클라이언트가 승자를 정하지 않으며, 경주 연출의 최종 우승자는 서버 결과와 같아야 한다. 판매 중에는 승자나 추첨용 비밀값을 공개하지 않는다.

목표 환급률은 95%다. 선수별 최저 우승 확률은 1%이며 최대 배당은 원금 포함 95배다. 배당은 원금을 포함하므로 100 그레인 티켓의 2배 당첨금은 총 200 그레인이다. 목표 환급률은 개별 경기나 개인에게 95% 환급을 보장한다는 뜻이 아니다. 표시 배당은 소수점 두 자리 아래를 버리고 실제 당첨금은 그레인 정수 아래를 버리므로 실제 기대 환급률은 95% 이하가 된다. 금액 계산은 서버가 BigInt로 수행하고 지갑에 저장할 결과는 안전한 정수 범위를 검사한다. [상세 확률·배당 산식](../슬라임-레이스-서버.md)을 따른다.

## 티켓과 그레인

- 그레인은 무료 지급만 하는 기존 사이트 공용 화폐다. 경주 전용 포인트로 분리하지 않으며 기존 지갑과 원장을 사용한다.
- 현금 구매·충전·환전, 상품·쿠폰·유료 아이템 교환, 타인 양도·송금, 유료 재화 전환은 제공하지 않는다. 무료 그레인 티켓의 취소 반환과 당첨금도 같은 무료 그레인으로 처리한다.
- 최소 구매 금액은 100 그레인이다. 보유 잔액 안에서 구매하며 정책상 별도 상한은 없다. 저장·계산의 안전한 정수 범위를 넘는 요청은 거절한다.
- 한 경기에서 여러 선수에게 금액을 나눌 수 있다. 판매 마감 전에는 선수별 총 티켓 금액을 수정하거나 전부 취소할 수 있다.
- 구매 시 실제 공용 그레인 지갑에서 차감한다. 수정은 기존 금액과 새 금액의 차액을 반영하고, 취소는 기존 금액을 반환한다.
- 당첨금 지급·취소 반환·구매 차감은 기존 계정의 지갑과 원장 DB에 기록한다. 브라우저 별도 잔액이나 예시 잔액을 실제 잔액처럼 쓰지 않는다.
- 원장과 잔액은 같은 트랜잭션에서 변경하며 중복 요청·수정 경합·재시작·정산 재실행으로 중복 차감·환급·당첨금이 생기지 않아야 한다.
- 신규 가입 이벤트 30,000 그레인의 기존 지급 자격과 횟수는 유지한다. 기존 회원 소급 지급, 현금 충전, 소진 시 자동 보충은 제공하지 않는다.
- 기금과 기간별 지급 예산에는 정책상 상한을 두지 않는다. 이 결정은 서버 비용 설정 변경이나 현금 결제를 허용하는 결정이 아니다.

공통 화폐의 기존 지급 정책과 정본 아이콘은 [그레인 기획](그레인-화폐-디자인.md)을 따른다.

## 성인 확인과 정보 공개

티켓은 성인 본인확인을 마친 회원만 구매할 수 있다. 2026-10-17 사용자가 **본인확인 서비스 연동 전 구매 잠금 유지**를 선택했다. 관람과 응원은 누구나 이용할 수 있고, 실제 본인확인 공급자 연동과 검증을 마친 뒤 구매 개방을 별도로 진행한다. 만 19세 자기확인 버튼이나 가짜 인증 완료 경로는 도입하지 않는다.

기존 계정의 `만 14세 이상` 가입 구분을 성인 본인확인으로 간주하지 않는다. 기존 회원의 나이를 가입 시기·메일·닉네임·소셜 공급자 등으로 추정하지 않는다. 실제 본인확인 서비스가 연결되지 않은 현재는 구매·수정·취소를 잠근다.

무료 그레인 정책을 적용해도 이 성인 확인 잠금을 자동으로 해제하지 않는다. 무료라는 이유로 법적 적합성이나 등급 분류 면제를 확정했다고 안내하지 않는다.

개인 손익·기록·적중률은 로그인한 본인에게만 제공한다. 타인 티켓·베팅 금액, 전체 합계·참여 인원·랭킹은 공개하지 않는다. 사용자 ID를 파라미터로 받아 다른 회원 정보를 반환하지 않는다.

화면과 API를 분리해도 인증·마감·잔액·연령 자격·소유권은 서버가 판단한다. GitHub Pages 화면에서 커뮤니티 서버로 통신할 때에는 레이스 API에만 정확한 허용 출처와 자격증명 CORS를 적용하고 기존 인증 API의 출처 보호를 넓히지 않는다.

## 소리와 접근성

첫 진입은 무음으로 시작하고 이용자가 소리 버튼으로 켤 수 있다. 화면을 다시 열었다는 이유로 소리를 자동 재생하지 않는다. `prefers-reduced-motion` 환경에서는 지속적인 이동·진동·깜박임을 줄이면서 경기 상태와 결과는 확인할 수 있게 한다. 창은 키보드로 열고 닫을 수 있으며 닫힌 창으로 초점이 이동하지 않아야 한다.

## 후속 작업과 배포 준비

앞선 기획에서는 지정 유료 아이템 교환을 후속으로 남겼으나 2026-10-17 무료 화폐 정책 결정으로 폐기했다. 현금·상품·쿠폰·유료 아이템 교환과 유료 재화 전환은 제공하지 않으며, 품목·가격·교환 기능을 후속 예정으로 남기지 않는다.

현재 `fly.toml`은 `auto_stop_machines = "stop"`, `min_machines_running = 0`으로 유휴 정지를 허용한다. 이번 공개에서도 기존 머신·볼륨과 이 설정을 유지했으며 상시 실행 비용 설정을 바꾸지 않았다. 이 상태에서 24시간 프로세스가 계속 실행된다고 설명할 수 없다. 정지 뒤에는 다음 시작 시 시각 기준으로 회차와 미정산을 회복한다. 상시 실행이 필요하면 운영 설정과 비용을 별도로 결정한다.

GitHub Pages는 정적 화면·자산, 커뮤니티 Fly 서버는 경기·인증·지갑·원장 권위를 맡는다. 배포 준비 때 새 서버 파일과 공개 자산이 `.dockerignore`의 명시 허용 목록에 포함되는지 확인하고, `_config.yml`의 서버·시험·문서 비공개 제외는 유지한다. 공개 배포는 조율자가 사용자 요청의 반영 범위와 검증 결과를 확인한 뒤 수행하고 실제 배포 기록을 남긴다.
