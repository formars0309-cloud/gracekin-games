# Gracekin Games 사이트

`gracekingames.com`의 게임 모음과 게임별 홈페이지, 커뮤니티를 관리한다. 대문에서 게임 홈페이지로 이동해 소개와 안내를 확인하고, **START**를 누르면 실제 게임이 열린다. 게임을 시작하기 전에 게임 화면이나 게임 자원을 불러오지 않는다.

- 사업체: Gracekin Games(그레이스킨 게임즈)

- 홈: '달밤의 극장'. 첫 화면을 대표작 두 무대(슬라임 라인, 경국지계)로 나눈다. 마우스를 올린 무대가 넓어지고, 경국지계는 인물 얼굴을 중심으로 확대된다. 그 아래 '모든 게임' 카드 목록은 게임이 늘면 카드만 더한다.

## 그레인 신규 가입 이벤트 (2026-10-16 공개)

공개 공통 계정 서버는 새 가입자가 이메일 확인을 마치면 계정당 한 번 **30,000 그레인**을 지급한다. 기존 회원은 미확인 회원을 포함해 소급 지급하지 않는다. 보호자 동의가 유효한 어린이도 같은 기준을 적용한다. 로그인한 본인은 `/account/`에서 잔액과 지급 내역을 확인할 수 있다. 잔액·자격·원장은 서버 DB에 영속 저장하며 이메일 확인과 지급은 같은 트랜잭션으로 처리한다. 중복 요청이나 서버 재시작으로 보상이 늘어나지 않는다.

실제 게임 사용과 일반 운영자 지급·결제·송금은 아직 제공하지 않는다. 2026-10-16 사용자의 요청으로 가입 보상과 지갑을 공개했다. 공개 화면·API·운영 데이터 보존을 확인했으며, 실제 가입·이메일 확인·지급은 운영과 분리한 DB에서 검증했다. 이벤트 종료일과 다른 경제 정책은 [그레인 기획](docs/기획/그레인-화폐-디자인.md), 저장 구조와 검증 절차는 [공통 계정 운영](docs/공통계정-운영.md)을 참고한다.

## 사이트 상단 계정 표시 (2026-10-16 공개)

대문·두 게임 소개·커뮤니티 상단에서 로그인한 본인의 닉네임과 그레인 잔액을 표시한다. 비회원에게는 로그인 링크를 제공하며 게임별 계정 이동 문맥을 유지한다. 로딩·오류에는 잔액 숫자를 비우고 계정 열기·다시 확인 경로를 제공한다. 페이지 이탈·숨김·포커스 해제 때 표시를 비우고 복귀 시 서버에 다시 확인한다. 브라우저 저장소에는 계정 표시나 인증값을 남기지 않는다.

GitHub Pages 대문에서 인증 서버의 기존 쿠키로 확인하기 위해 표시 전용 `GET /api/account/summary`만 HTTPS 대문과 `www`의 자격증명 CORS 요청을 허용한다. 이메일·회원 ID·원장·인증값은 이 API에 포함하지 않으며 기존 쿠키 범위와 다른 API의 출처 보호는 유지한다. [상세 경계와 검증](docs/공통계정-운영.md)을 참고한다. 2026-10-16 사용자의 요청으로 Fly·GitHub Pages에 공개했다. 실제 공개 환경에서는 비회원 화면·출처 간 조회와 CORS 차단을 확인했으며, 로그인한 본인 닉네임·잔액 표시는 격리 DB에서 검증했다. 운영 시험 계정은 만들지 않았다.

## 제보·의견 받기

누구나 로그인 없이 보낼 수 있는 구글 설문지로 받는다(2026-10-14). 사업자 구글 계정의 드라이브에 설문지와 응답 스프레드시트 「Gracekin Games 버그 제보·의견(응답)」이 있다. 이메일은 수집하지 않는다. 경국지계는 게임 안의 '문제 신고'·'소감 남기기'로도 받는다.

## 커뮤니티

회원 커뮤니티의 정식 출처는 `https://community.gracekingames.com`이며, 2026-10-16 도메인 전환과 공통 계정 공개 배포를 완료했다. 전용 Fly 앱 `gracekin-games-community`와 기존 데이터는 유지한다. 배포 이력과 운영 확인 결과는 [커뮤니티 배포 기록](docs/커뮤니티-배포.md)에 적었다. Resend를 통해 신규 가입·이메일 인증·비밀번호 복구를 제공하며, 만 14세 미만은 보호자 동의 회신을 자동 확인한 뒤 가입하도록 한다. 기존 계정 로그인과 공개 글 읽기도 유지한다. 대문과 게임 홈페이지의 주소·DNS는 기존대로 유지한다.

운영 발송 서비스는 Resend로 정했고 `mail.gracekingames.com` 도메인 인증을 완료했다. 발신은 `account@mail.gracekingames.com`이며, 문의·동의 철회 주소는 `support@gracekingames.com`이다. 자동 동의 회신은 안내 메일에 지정한 별도 Resend 수신 주소로 받는다. 실제 SMTP 발송·도착, ImprovMX를 통한 운영자 Gmail 수신, Resend의 직접 수신과 서명된 알림을 확인했다. 일반 가입·인증·복구의 격리 DB 통합시험 24항목과 실제 회신 자료를 사용한 별도 자동 승인·보류·어린이 가입 시험을 통과했다. 업체별 처리 국가·보관 조건은 공개 방침과 보호자 동의문에 반영하고 [연결 순서와 검증 범위](docs/공통계정-운영.md)를 기록했다. 발송 리전이 도쿄여도 Resend의 저장·주요 처리는 미국에서 이뤄진다.

옛 주소의 GET·HEAD 화면 요청은 같은 경로·쿼리의 새 주소로 301 이동한다. 옛 주소의 `/api`와 `/api/…`, 그 외 메서드, 임의 Host는 403으로 거부한다. Pages에서 넘기는 주소도 새 출처로 고정하며 경로·쿼리·해시를 유지한다. 주소가 바뀌면 기존 로그인 세션은 이어지지 않아 한 번 다시 로그인해야 한다. 공통 계정 서버의 배포 완료와 메일 기능의 활성화는 구분한다.

게임마다 게시판과 공식 안내를 분리한다. 슬라임 라인은 자유게시판(`free`)·공략과 팁(`guide`)·갤러리(`gallery`)·공지사항(`notice`), 경국지계는 자유게시판(`free`)·덱 연구(`deck`)·전략과 공략(`strategy`)·공지사항(`notice`)을 제공한다. `board`가 없으면 공지사항을 연다.

게시판 분류 이동, 제목·내용 검색, 페이지 이동, 공식 안내 읽기와 목록 복귀를 이용할 수 있다. 공식 안내는 게임별로 환영 안내(`post=welcome`), 시작 안내(`post=play-guide`), 제보 안내(`post=feedback`) 3개다. 예: `/community/?game=slimeline&board=notice&post=welcome`.

공통 계정의 로그인 화면은 `/account/`다. 기존 커뮤니티 계정과 회원 식별자를 그대로 사용한다. 만 14세 이상은 연령 구분을 선택하고 이메일·닉네임·비밀번호로 가입하며, 새 계정은 이메일 확인 뒤 로그인한다. 만 14세 미만은 보호자의 명시적 동의 회신이 확인 조건을 통과해 승인된 뒤 가입할 수 있다. 어린이 계정은 커뮤니티 읽기만 가능하고 서버와 화면 모두 글·댓글 작성을 차단한다. 비회원도 공개 글을 읽을 수 있으며, 작성 권한이 있는 계정은 본인 글·댓글을 수정·삭제할 수 있다. 두 게임의 실제 계정 연결은 아직 제공하지 않는다. 갤러리는 텍스트 글만 지원하며 사진·파일 첨부는 제공하지 않는다. 공식 공지는 기존 안내로 유지한다.

계정·세션·글·댓글은 서버의 실제 데이터베이스에 저장한다. 브라우저 저장소를 공용 게시판처럼 사용하지 않는다. 서버 연결이 끊기면 실패 안내와 입력 내용을 유지하고, 공식 안내는 계속 읽을 수 있다. 이메일 인증·재발송·비밀번호 재설정 기능을 구현했다. 운영 메일을 설정하지 않은 환경에서는 신규 가입과 메일 기능을 닫고 기존 계정 로그인은 유지한다. 제보와 의견은 기존 구글 설문지로 보내며, 계정·글·댓글의 공통 방침은 `/community/privacy/`로 연결한다. 게임별 개인정보처리방침과 문의 메일 `support@gracekingames.com`도 유지한다. Fly 커뮤니티에서 대문·게임 홈페이지로 돌아가면 실제 `gracekingames.com` 주소가 열린다.

## 공통 계정 1차 배포와 후속 기획 (2026-10-16)

[gracekingames 공통 계정과 게임 연결 기획](docs/기획/공통-계정과-게임-연결.md)에 **게스트로 먼저 체험하고 필요한 기능에서 가입하는 방식**을 반영했다. 슬라임 라인 기본 플레이와 경국지계 튜토리얼·AI전·일반 체험은 게스트로 이용하게 한다. 일반 실시간 PvP의 구체적 범위는 별도 확정한다. 첫 화면에는 ‘바로 시작’과 ‘로그인’ 진입을 마련하고, 플레이를 가입창으로 강제로 끊지 않는다.

공통 계정은 플레이 기록 연결과 커뮤니티 글·댓글 작성에 필요하다. 경국지계 랭크·대회, 다른 기기 이어하기도 해당 기능을 제공할 때 공통 계정을 요구하며, 이 기능들의 구현 완료나 출시 시점을 뜻하지 않는다. 사이트와 각 게임에서 공통 가입·로그인을 시작하고 인증 후 원래 게임으로 복귀한다. 신규 가입자는 방금 게스트로 플레이한 기록을 이어받으며, 두 게임의 진행도·재화·기록은 각각 관리한다. 이미 기록이 있는 계정과 충돌하면 자동으로 합치거나 덮어쓰지 않는다.

사용자는 두 게임 모두 현재 실제 이용자 0명이라고 확인했다. 따라서 기존 게임 이용자의 계정·진행도·구매 내역 이전과 전환 유예는 1차 범위에서 제외한다. 커뮤니티 회원까지 0명으로 추정하거나 기존 데이터를 삭제하지 않으며, 회원과 글·댓글이 있다면 그 관계를 보존한다.

만 14세 미만 가입은 보호자 성명·이메일로 신청 → 동의 내용 이메일 발송 → 보호자 회신 자동 확인·승인 → 신청한 브라우저에서 어린이 계정 생성 순서다. 반복적인 운영자 승인 대신 정해진 회신 양식과 메일 인증 결과를 확인한다. 보호자는 인용문·서명·첨부파일 없이 안내된 7줄만 새 회신 본문에 넣어 보낸다. 확인이 어려운 회신은 보류하고 다시 회신하거나 문의할 방법을 안내한다. 동의 전 어린이 정보는 입력받지 않으며, 승인된 신청은 가입에 한 번만 사용할 수 있다. 이메일을 열거나 링크를 클릭하는 것만으로 동의 처리하지 않는다. 동의 상태는 직접 새로고침할 수 있고 페이지를 새로고침한 뒤에도 HttpOnly 쿠키로 이어진다. 어린이 계정은 커뮤니티 읽기만 허용한다. 동의 철회는 운영자 확인 후 세션을 무효화하고 이후 로그인을 차단한다.

이번 구현 범위는 사이트 공통 이메일 계정, 기존 커뮤니티 계정 유지, 이메일 확인·복구, 보호자 동의와 어린이 가입이다. 메일 링크의 인증값은 URL 해시로 전달하고 화면 진입 즉시 주소에서 제거한다. 이메일 확인도 사용자가 버튼을 눌러야 처리되며, 계정 화면에는 외부 통계 스크립트를 넣지 않는다. 실제 게임 서버의 공통 로그인 연결·게스트 기록 이전·클라우드 저장·소셜 로그인·결제·대회는 후속 작업이다. 일반 메일 활성화 때 업체별 국외 처리 고지와 동의문 v2를 반영했고, 자동 회신에는 수신 처리와 증빙 보관을 설명한 v3를 사용한다. 실제 가입·인증·복구와 회신 자동 승인·보류·어린이 가입 권한은 운영과 분리한 DB에서 검증했다. 운영 서버에서는 실제 수신 연결과 서명을 확인했으며 시험 회원·보호자 신청을 만들지 않았다. 각 검증 범위와 최종 개방 상태는 배포 기록에 구분한다.

## 보호자 회신 자동 확인 (2026-10-16)

사용자는 보호자 회신을 매번 직접 승인하는 대신 자동 처리를 요청했다. `email-reply-auto` 방식은 Resend의 서명된 수신 알림과 API로 가져온 회신을 대조하고, 같은 발신 주소·신청 번호·메일로만 보낸 확인값·동의문 버전·명시적 법정대리인 진술·동의 문구가 맞을 때만 승인한다. 회신 내용이 불명확하면 보류하며 신청 화면에서 이유를 확인할 수 있다. 생성형 AI에 원문을 보내 해석하게 하지 않으며, 이메일로 법정대리인의 실제 신원을 인증했다고 설명하지 않는다.

기존 SMTP 발송 전용 키와 별도로 수신용 Full access API 키·웹훅 서명키를 설정하며 실제 값은 저장소에 넣지 않는다. Resend 기본 수신 주소를 연결해 DNS 추가 없이 실제 수신을 확인했고 기존 루트 ImprovMX 수신 설정은 유지했다. 자동 확인으로도 법정대리인의 실제 신원을 보증하지 않으며 문의·철회·삭제 요청은 지원 메일로 받는다. 연결 설정, 실제 수신과 격리 DB 시험, 최종 개방 확인은 [공통 계정 운영](docs/공통계정-운영.md)에 구분해 적었다.

## 방문 통계 (2026-10-15)

Umami Cloud(무료 Hobby, 사이트 1개, 월 10만 이벤트, 6개월 보관)로 센다. 쿠키를 쓰지 않고 개인정보를 모으지 않는다. `data-domains`로 실제 도메인에서만 보내고, 브라우저의 추적 거부(Do Not Track) 설정은 따른다. 그래서 로컬 미리 보기에서는 기록이 남지 않는다.

- 방문: 주소 꼬리표까지 남는다. 채널별 링크에 `?ref=blog`, `?ref=threads`, `?ref=youtube`, `?ref=kakao`, `?ref=reddit`처럼 붙인다.
- 대문 → 게임 홈페이지: `homepage-slimeline`, `homepage-gyeongguk`(속성 `from` = `stage` 첫 화면 무대, `card-image`, `card-button`). 게임 실행 횟수와 구분한다.
- 게임 홈페이지 START → 실제 게임: `play-slimeline`, `play-gyeongguk`. 클릭 의도를 세며 실제 로딩 완료나 플레이 시간은 뜻하지 않는다.
- 제보 설문지 이동: `feedback-form`. 제출 완료 횟수는 뜻하지 않는다.
- 계정 화면 `/account/`는 외부 방문 통계를 사용하지 않는다.
- 대문·게임별 홈페이지·커뮤니티에 같은 사이트 ID와 실제 도메인 제한, 추적 거부 설정을 적용한다. 현재 도메인 제한은 `gracekingames.com`이므로 `community.gracekingames.com`의 커뮤니티 방문도 이 통계에 포함하지 않는다.
- 바닥글에 "방문 통계는 쿠키 없이, 누구인지 알 수 없는 형태로만 셉니다." 한 줄을 넣었다. 디자인 캔버스 HomeB에는 없는 줄이다.

## 로컬 실행과 검증

Node.js는 **24.15.0 이상인 24.x 버전**이 필요하다(`package.json`의 `engines`: `>=24.15.0 <25`). 처음 저장소를 내려받은 환경에서는 의존성을 설치한 뒤 서버를 시작한다.

```sh
npm ci
npm start
```

기본 주소는 `http://127.0.0.1:8766`이다. 회원·세션·게시글·댓글·그레인 잔액과 지급 내역은 `.data/community.sqlite`에 저장되므로 서버를 다시 시작해도 유지된다. 개발용 세션 비밀값은 `.data/auth-secret`으로 관리되며 공개하거나 커밋하지 않는다. `HOST`, `PORT`, `DATA_DIR`로 로컬 실행 환경을 바꿀 수 있다.

```sh
npm test
```

GitHub Pages만으로는 회원가입·로그인·공유 글쓰기·댓글을 실행할 수 없다. 정적 파일만 열면 공식 안내를 읽을 수 있고, 회원 기능은 서버 연결 안내를 표시한다. 커뮤니티 도메인 전환과 공통 계정 서버는 2026-10-16 배포 완료했다. Resend를 통해 가입·인증·복구와 보호자 동의 회신을 처리한다. 만 14세 미만은 동의 승인을 거쳐 가입하며 커뮤니티 읽기만 허용한다. 검증 범위는 [배포 기록](docs/커뮤니티-배포.md)에서 확인할 수 있다.

정적 사이트 검증기는 위의 Node.js 서버 테스트와 별도이며, 실행하려면 **Python 3**가 설치되어 있어야 한다. 게임별 페이지를 통합한 뒤 내부 링크·자산, START 이동, 게임 사전 실행 여부, 게임별 안내 분리와 민감정보 패턴을 확인한다.

```sh
python3 scripts/verify_site.py
```
