그레이스킨게임즈 공통 계정을 삭제하려면 가입한 이메일 주소로 support@gracekingames.com에 요청해 주세요. 삭제 대상과 요청 방법, 처리 기간을 아래에서 안내합니다.

메일 제목은 계정 삭제 요청, 본문에는 닉네임을 적어 주세요. 비밀번호·세션 쿠키·인증키는 보내지 마세요.

요청을 접수하면 본인 여부를 확인하고 접수 후 7일 이내 삭제한 뒤 결과를 회신합니다. 작성한 글·댓글도 함께 삭제하므로 남기고 싶은 글이 있으면 요청에 적어 주세요.

1. 적용 대상

이 안내는 그레이스킨게임즈 공통 계정(사이트 계정·커뮤니티·슬라임 레이스)에 적용합니다.

슬라임 라인·경국지계 게임 안의 계정과 진행 기록은 각 게임의 개인정보처리방침에 따릅니다. 경국지계는 공통 계정으로 로그인할 수 있으며, 게임 진행 기록에는 경국지계의 개인정보처리방침을 적용합니다. 슬라임 라인의 게임 계정과 진행 기록은 현재 공통 계정과 연결되어 있지 않습니다.

2. 요청 방법

  1. 가입한 이메일 주소로 support@gracekingames.com에 메일을 보냅니다.
  2. 제목에 계정 삭제 요청, 본문에 닉네임을 적습니다.
  3. 남기고 싶은 글이 있다면 어떤 글인지 요청에 함께 적습니다.

비밀번호·세션 쿠키·인증키는 보내지 마세요. 가입한 이메일 주소를 더 이상 사용할 수 없다면 그 사정을 적어 주세요. 본인 확인 방법을 안내하겠습니다.

만 14세 미만 어린이 계정은 가입에 동의한 보호자가 보호자 이메일로 요청해 주세요.

3. 처리 절차와 기간

  1. 가입한 이메일 주소로 보낸 요청인지 확인합니다. 필요한 경우 회신으로 본인 여부를 확인합니다. 어린이 계정은 동의한 보호자와 대상 계정의 관계를 확인합니다.
  2. 삭제 전에 기존 로그인 세션을 먼저 끊고, 접수 후 7일 이내 계정을 삭제합니다.
  3. 요청한 이메일 주소로 처리 결과를 회신합니다.

4. 삭제되는 정보

개인정보처리방침 5절에 따라 다음 정보를 함께 삭제합니다.

  • 계정·세션·인증 정보: 이메일, 닉네임, 비밀번호 해시, 소셜 연결 정보
  • 그레인 잔액·이벤트 자격·지급 내역
  • 레이스 티켓·정산·중복 요청 처리 내역
  • 출석·활동 보상 기록
  • 커뮤니티 신고·버그 제보·운영자 조치 기록
  • 보호자 동의 자료
  • 작성한 글·댓글

작성한 글·댓글은 기본적으로 함께 삭제합니다. 남기고 싶은 글이 있으면 삭제 요청에 적어 주세요. 해당 글은 작성자 표시만 지우고 남깁니다.

5. 남는 정보

법령상 별도 보관 의무가 있는 항목은 보관 사유·범위·기간을 먼저 안내합니다.

운영 백업과 메일 발송업체 로그는 개인정보처리방침 4절과 5절의 보관 기한에 따라 만료·삭제되며, 계정 삭제와 동시에 모든 사본이 즉시 지워지지는 않습니다.

다른 곳에 복사·공유된 게시물은 해당 서비스에 별도로 삭제를 요청해야 합니다.
