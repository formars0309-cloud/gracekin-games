그레이스킨게임즈 계정·커뮤니티

개인정보처리방침

적용일: 2026년 10월 16일

이 방침은 슬라임 라인과 경국지계의 사이트 공통 계정과 공식 커뮤니티 게시판에 적용합니다. 기존 커뮤니티 계정도 같은 계정으로 이용합니다. 두 게임 안의 계정·기록 연결과 클라우드 저장은 아직 제공하지 않습니다. 운영자는 그레이스킨게임즈이며, 개인정보 문의는 support@gracekingames.com으로 받습니다.

현재 운영 메일 연결을 준비 중입니다. 신규 회원가입·이메일 인증·비밀번호 복구·보호자 동의 신청은 아직 제공하지 않습니다. 기존 계정의 로그인과 공개 글 읽기는 계속 이용할 수 있습니다. 아래의 신규 가입·이메일·보호자 동의 절차는 해당 기능을 활성화한 뒤 적용합니다.

이메일과 비밀번호는 로그인에 사용합니다. 닉네임·글·댓글은 로그인하지 않은 사람도 읽을 수 있습니다. 회원정보와 게시물은 일본 도쿄의 커뮤니티 서버에 보관합니다.

신규 가입 기능을 활성화하면 가입 전에 만 14세 이상 여부를 자기 확인으로 선택합니다. 만 14세 미만은 법정대리인의 동의 회신을 운영자가 검토·승인한 뒤 계정 정보를 입력합니다. 어린이 계정은 커뮤니티 읽기만 제공하며 글·댓글 작성은 허용하지 않습니다. 생년월일을 수집하거나 자기 확인만으로 실제 연령을 증명했다고 처리하지 않습니다.

1. 처리 목적과 항목

계정 생성·로그인, 게시판 제공, 본인 글·댓글의 변경 권한 확인, 서비스 보안과 오남용 예방을 위해 다음 정보를 처리합니다.

구분처리하는 정보사용 목적
회원가입이메일, 닉네임, 비밀번호의 해시값, 내부 계정 식별자, 가입·갱신 시각, 이메일 확인 여부, 가입 시 선택한 연령 구분(만 14세 이상·미만)계정 생성, 로그인과 작성자 확인

이메일 인증·복구이메일, 일회용 인증값의 보호된 저장값과 만료 시각이메일 확인, 비밀번호 재설정, 인증값의 만료·재사용 방지
보호자 동의 신청법정대리인 성명·이메일, 신청 번호·상태·시각, 신청 브라우저 확인값의 해시, 동의문·버전, 동의 회신 증빙과 운영자 검토 기록, 가입 후 자녀 계정 식별자동의 안내와 회신 확인, 어린이 가입 허용, 동의 철회 처리
이메일 문의보낸 사람의 이메일 주소와 문의 내용문의 답변, 개인정보 권리 요청과 본인 확인

비밀번호는 가입·로그인 요청 때 암호화된 통신으로 전송하고, 서버에는 평문 대신 해시값을 저장합니다. 이메일은 게시판이나 공개 글·댓글 조회 응답에 표시하지 않습니다. 연령 구분은 가입자가 선택한 값이며 생년월일을 요구하지 않습니다. 기존 계정의 연령을 임의로 추정해 저장하지 않습니다.

새 계정은 이메일 확인 후 로그인할 수 있으며, 비밀번호를 재설정하면 기존 로그인 세션을 무효화합니다. 이메일 발송을 연결하지 않은 환경에서는 새 회원가입·인증·복구·보호자 동의 신청을 제공하지 않고 기존 계정의 로그인은 유지합니다. 어린이의 실명·전화번호·주소·결제정보는 가입에 요구하지 않습니다. 동의 확인 전에는 어린이의 닉네임·이메일·비밀번호를 받지 않습니다. 로그인용 이메일은 아직 가입되지 않은 보호자 이메일을 사용할 수도 있으나, 같은 이메일이라는 이유로 기존 계정과 자동 연결하지 않습니다.

보호자 동의 절차와 이용 범위

보호자 동의 신청은 운영 메일 연결을 준비 중이며, 아래 절차는 기능 활성화 이후 적용합니다.

먼저 보호자 성명과 이메일만 받아 동의 내용을 보냅니다. 보호자가 법정대리인임을 밝히고 개인정보 처리와 어린이 가입에 동의한다는 내용을 회신하면, 운영자가 회신과 법정대리인 확인 자료를 검토한 뒤 승인합니다. 메일을 열거나 링크를 누르는 것만으로 동의나 본인 확인이 완료되지 않습니다. 별도의 휴대전화 본인인증 기능은 제공하지 않습니다.

승인된 신청은 신청한 브라우저에서만 가입에 한 번 사용할 수 있습니다. 어린이 계정은 가입 후에도 로그인용 이메일을 확인해야 합니다. 동의를 거부하면 어린이 회원가입은 할 수 없으나, 가입 없이 가능한 게임 체험과 공개 글 읽기는 이용할 수 있습니다. 이번 동의에는 결제·대회 참가가 포함되지 않습니다.

법정대리인은 동의 메일의 회신 주소 또는 support@gracekingames.com으로 개인정보 열람·정정·삭제·처리 정지와 동의 철회를 요청할 수 있습니다. 운영자는 요청자와 대상 계정의 관계를 확인하여 처리합니다. 동의를 철회하면 어린이 계정의 로그인을 차단하고 기존 세션을 무효화합니다. 계정·증빙의 삭제는 아래 보관·삭제 절차에 따라 별도로 처리합니다.

2. 공개되는 정보

글·댓글 작성이 허용된 계정의 닉네임, 작성한 글과 댓글, 작성·수정 시각은 누구나 볼 수 있습니다. 게시물 주소가 다른 곳에 공유되거나 검색 서비스에 노출될 수 있으니, 본인이나 다른 사람의 이메일·전화번호·주소·비밀번호 등 공개하면 안 되는 정보를 쓰지 마세요.

운영자가 회원정보를 광고 목적으로 판매하거나 제공하는 기능은 없습니다. 아래의 서버 보관과 통계 처리, 이용자가 직접 공개한 게시물은 각각의 설명을 확인해 주세요.

3. 로그인 쿠키와 방문 통계

로그인을 유지하기 위해 인증용 쿠키를 사용합니다. 운영 서버의 세션 쿠키에는 HttpOnly·Secure·SameSite 설정을 적용합니다. 쿠키를 차단하면 로그인 기능을 이용할 수 없으며, 브라우저 설정에서 쿠키를 지울 수 있습니다.

세션의 기본 유효기간은 7일이고 이용 중 갱신될 수 있습니다. 로그아웃하면 해당 세션을 무효화합니다. 유효기간이 지났다는 이유만으로 모든 서버 기록이 같은 시각에 자동 삭제되는 것은 아닙니다.

대표 사이트의 Umami 방문 통계는 쿠키를 사용하지 않으며, 이메일·닉네임·게시글 본문을 별도 통계 이벤트로 전송하지 않습니다. 브라우저의 추적 거부(Do Not Track) 설정을 따릅니다. 현재 통계 전송 도메인은 gracekingames.com으로 제한하며, community.gracekingames.com의 커뮤니티 방문 통계는 전송하지 않습니다. 계정 가입·로그인·메일 확인·비밀번호 재설정 화면에는 외부 통계 스크립트를 넣지 않습니다. 보호자 동의 신청을 이어가기 위한 별도의 HttpOnly 쿠키를 사용하며, 동의 신청 상태 확인과 승인된 브라우저에서의 가입에만 사용합니다. 인증용 세션 쿠키와 동의 신청 쿠키는 방문 통계와 별개입니다.

Fly.io의 인프라 운영과 개인정보 처리에 관한 설명은 Fly.io 개인정보처리방침과 공식 계약 문서 안내에서 확인할 수 있습니다.

5. 보관·삭제와 이용자의 요청

계정과 작성한 글·댓글은 서비스를 제공하는 동안 보관합니다. 필요가 끝나거나 계정·개인정보 삭제 요청을 받으면 본인 확인과 처리에 필요한 사항을 확인하여 삭제합니다. 법령에 따라 별도 보관이 필요한 경우에는 해당 사유와 범위를 확인해 안내합니다.

본인이 작성한 글과 댓글은 로그인 후 직접 삭제할 수 있습니다. 현재 계정 자동 탈퇴 화면은 제공하지 않으므로, support@gracekingames.com으로 계정 삭제를 요청해 주세요. 다른 곳에 복사·공유된 게시물은 해당 서비스에 별도 삭제 요청이 필요할 수 있습니다.

개인정보 열람·정정·삭제·처리 정지도 같은 메일로 요청할 수 있습니다. 요청 내용과 본인 여부를 확인해 처리 방법을 안내합니다. 문의할 때 비밀번호·세션 쿠키·인증키를 보내지 마세요. 문의에 필요한 정보는 문의와 후속 처리가 끝나면 삭제하며, 별도 보관 사유가 있으면 안내합니다.

가입하지 않은 보호자 동의 신청은 신청 후 7일이 지나 만료되거나 가입 전에 철회하면 보호자 성명·이메일과 보관한 승인 회신 원문을 삭제합니다. 서버를 시작할 때와 운영 중 1시간마다 정리하며, 운영자가 수동으로 정리할 수도 있습니다. 서버가 꺼져 있으면 다음 시작 때 처리합니다. 삭제된 회원에 연결되어 있던 동의 자료도 정리합니다.

가입한 어린이의 동의를 철회하면 우선 기존 로그인 세션과 새 로그인을 차단합니다. 보호자의 삭제 요청과 대상 계정을 확인한 뒤 삭제를 처리하면 어린이 계정·세션·인증정보와 동의 증빙을 삭제합니다. 별도 보관 의무가 있는 경우에는 그 사유와 범위를 먼저 확인해 안내합니다.

이 정리는 현재 운영 데이터베이스와 동의 증빙 폴더의 사본에 적용합니다. 운영 백업은 정해진 보관 기한에 따라 별도로 만료·삭제합니다. 서비스 제공업체의 저장 장치 등에 남은 사본은 해당 보관·삭제 절차를 함께 확인해 안내하며, 모든 사본이 즉시 삭제되는 것은 아닙니다.

6. 보호 조치

HTTPS 통신, 비밀번호 해시 저장, 인증 쿠키 보호, 서버에서의 작성자 권한 확인과 요청 빈도 제한을 적용합니다. 데이터베이스와 인증 설정 파일은 공개 정적 파일 경로에서 제공하지 않습니다. 운영자 접근 권한과 파일 접근 권한을 제한합니다.
